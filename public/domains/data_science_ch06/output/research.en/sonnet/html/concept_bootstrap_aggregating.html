Bootstrap Aggregating

Definition. Let $\mathcal{D} = \{(\mathbf{x}_i, y_i)\}_{i=1}^{n}$ be a training dataset. A bootstrap sample $\mathcal{D}^{(b)}$ is a dataset of size $n$ drawn from $\mathcal{D}$ uniformly with replacement, so each observation may appear zero, one, or multiple times. Bootstrap aggregating (bagging) trains $B$ base learners $\hat{f}^{(1)}, \ldots, \hat{f}^{(B)}$ on independently drawn bootstrap samples $\mathcal{D}^{(1)}, \ldots, \mathcal{D}^{(B)}$ and combines their predictions:

$$\hat{f}_{\text{bag}}(\mathbf{x}) = \frac{1}{B} \sum_{b=1}^{B} \hat{f}^{(b)}(\mathbf{x}) \quad \text{(regression)}$$ $$\hat{f}_{\text{bag}}(\mathbf{x}) = \operatorname*{argmax}_{k} \sum_{b=1}^{B} \mathbf{1}\!\left[\hat{f}^{(b)}(\mathbf{x}) = k\right] \quad \text{(classification, majority vote)}$$

Worked Example. Suppose $n = 6$ and $\mathcal{D} = \{1, 2, 3, 4, 5, 6\}$ (scalar outputs for simplicity). One bootstrap sample might be $\mathcal{D}^{(1)} = \{2, 2, 3, 5, 5, 6\}$ and another $\mathcal{D}^{(2)} = \{1, 1, 3, 4, 4, 6\}$. The sample means are $\bar{y}^{(1)} = 3.83$ and $\bar{y}^{(2)} = 3.17$. The bagged estimate is $\hat{f}_{\text{bag}} = (3.83 + 3.17)/2 = 3.5$, matching the true population mean $3.5$. Averaging cancels the idiosyncratic sampling noise present in each individual estimate.

Key Theorem (Variance Reduction). If the $B$ base learners each have variance $\sigma^2$ and pairwise correlation $\rho \in [0,1]$, the variance of their average satisfies

$$\operatorname{Var}\!\left(\hat{f}_{\text{bag}}\right) = \rho\,\sigma^2 + \frac{1-\rho}{B}\,\sigma^2.$$

As $B \to \infty$ the variance converges to $\rho\,\sigma^2$, not zero, because bootstrap samples drawn from the same $\mathcal{D}$ remain correlated. Bagging therefore yields the greatest benefit when base learners are high-variance, low-bias (e.g., deep decision trees) and when $\rho$ is small.

Lab Cell.

from sympy import symbols, Rational, simplify

rho, sigma2, B = symbols('rho sigma2 B', positive=True)
var_bag = rho * sigma2 + (1 - rho) / B * sigma2
print("Bagged variance:", simplify(var_bag))
# Limiting variance as B → ∞
print("Limit B→∞:", var_bag.limit(B, float('inf')))  # → rho * sigma2

Running this cell confirms that the irreducible floor $\rho\,\sigma^2$ persists regardless of ensemble size, underscoring why diversity among learners — achieved through techniques such as feature subsampling in random forests — is as important as the aggregation step itself.
