Big Data

Definition. A dataset is said to exhibit big data characteristics when its volume, velocity, or variety (the "three Vs") exceed the processing capacity of conventional single-machine systems. More precisely, let $N$ denote the number of records, $d$ the number of features per record, and $\tau$ the arrival rate (records per second). A dataset is operationally classified as big data when any one of the following conditions holds:

$$N \cdot d > M_{\text{RAM}}, \qquad \tau > \lambda_{\text{disk}}, \qquad \text{or} \quad \dim(\mathcal{S}) \text{ is heterogeneous},$$

where $M_{\text{RAM}}$ is available memory, $\lambda_{\text{disk}}$ is sustainable write throughput, and $\mathcal{S}$ is the schema space. The hallmark challenge is that standard $O(N)$ or $O(N \log N)$ algorithms become infeasible when $N \sim 10^9$ or larger, forcing a shift to distributed or streaming paradigms.

Worked Example. Suppose a retailer logs $N = 10^9$ transactions, each described by $d = 50$ floating-point features stored as 64-bit doubles. The raw storage requirement is

$$S = N \cdot d \cdot 8 \text{ bytes} = 10^9 \times 50 \times 8 = 4 \times 10^{11} \text{ bytes} = 400 \text{ GB}.$$

A workstation with 32 GB of RAM cannot load this dataset into memory; a naive pandas read_csv call would raise a MemoryError. The solution is to partition the data into $k$ shards of size $\lceil N/k \rceil$ each, process each shard independently, and aggregate partial statistics. For the sample mean $\bar{x}$, the aggregation is exact:

$$\bar{x} = \frac{1}{N} \sum_{i=1}^{k} n_i \bar{x}_i, \qquad n_i = \left\lceil \frac{N}{k} \right\rceil.$$

Key Theorem (Embarrassingly Parallel Reduction). Let $f: \mathbb{R}^d \to \mathbb{R}$ be a decomposable statistic, meaning $f(\mathcal{D}) = g\!\left(f(\mathcal{D}_1), \ldots, f(\mathcal{D}_k)\right)$ for some aggregator $g$. Then the total computation time satisfies $T_k = T_1 / k + T_{\text{comm}}$, where $T_{\text{comm}}$ is network overhead. When $T_{\text{comm}} \ll T_1$, near-linear speedup is achieved. Sum, count, min, max, and histogram bin counts are all decomposable; median and exact quantiles are not.

Lab Cell.

import sympy as sp

N, k, n_i = sp.symbols('N k n_i', positive=True)
x_bar_i   = sp.Symbol(r'\bar{x}_i')

# Symbolic mean aggregation formula
x_bar_global = sp.Rational(1, 1) * sp.Sum(n_i * x_bar_i, (sp.Symbol('i'), 1, k)) / N
sp.pprint(sp.Eq(sp.Symbol(r'\bar{x}'), x_bar_global))

# Concrete shard size example
shard_size = sp.ceiling(sp.Integer(10**9) / 32)
print(f"Records per shard (32 shards): {shard_size}")
