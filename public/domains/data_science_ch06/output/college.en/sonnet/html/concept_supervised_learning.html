Supervised Learning

Definition. Supervised learning is a paradigm of machine learning in which an algorithm infers a mapping $f : \mathcal{X} \to \mathcal{Y}$ from a finite set of labeled examples $\mathcal{D} = \{(\mathbf{x}_i, y_i)\}_{i=1}^{n}$, where each input $\mathbf{x}_i \in \mathcal{X} \subseteq \mathbb{R}^d$ is paired with a target label $y_i \in \mathcal{Y}$. When $\mathcal{Y} \subseteq \mathbb{R}$ the task is called regression; when $\mathcal{Y}$ is a finite discrete set the task is called classification. The learned hypothesis $\hat{f}$ is selected from a hypothesis class $\mathcal{H}$ by minimizing an empirical risk:

$$\hat{f} = \argmin_{h \in \mathcal{H}} \frac{1}{n} \sum_{i=1}^{n} \ell\!\left(h(\mathbf{x}_i),\, y_i\right),$$

where $\ell : \mathcal{Y} \times \mathcal{Y} \to \mathbb{R}_{\geq 0}$ is a loss function measuring prediction error.

Worked Example. Consider a dataset of $n = 4$ points lying near the line $y = 2x + 1$:

| $x$ | $y$ | |-----|-----| | 1 | 3.1 | | 2 | 5.0 | | 3 | 6.8 | | 4 | 9.2 |

We restrict $\mathcal{H}$ to affine functions $h(x) = wx + b$ and use the squared loss $\ell(\hat{y}, y) = (\hat{y} - y)^2$. Minimizing the empirical risk over $w$ and $b$ yields the ordinary least-squares solution:

$$\hat{w} = \frac{\sum_i (x_i - \bar{x})(y_i - \bar{y})}{\sum_i (x_i - \bar{x})^2}, \qquad \hat{b} = \bar{y} - \hat{w}\,\bar{x}.$$

Computing from the table gives $\hat{w} \approx 2.03$ and $\hat{b} \approx 0.95$, closely recovering the true line.

Key Theorem (Bias–Variance Decomposition). For squared loss, the expected prediction error at a test point $\mathbf{x}$ decomposes as

$$\mathbb{E}\!\left[(y - \hat{f}(\mathbf{x}))^2\right] = \underbrace{\left(\mathbb{E}[\hat{f}(\mathbf{x})] - f(\mathbf{x})\right)^2}_{\text{bias}^2} + \underbrace{\mathrm{Var}[\hat{f}(\mathbf{x})]}_{\text{variance}} + \underbrace{\sigma^2}_{\text{irreducible noise}}.$$

This identity shows that reducing bias (e.g., by enlarging $\mathcal{H}$) typically increases variance, establishing the fundamental bias–variance trade-off that governs model selection.

from sympy import symbols, Rational, simplify

x, w, b = symbols('x w b')
data = [(1, Rational(31,10)), (2, 5), (3, Rational(34,5)), (4, Rational(46,5))]
n = len(data)
x_bar = sum(xi for xi,_ in data) / n
y_bar = sum(yi for _,yi in data) / n
w_hat = sum((xi-x_bar)*(yi-y_bar) for xi,yi in data) / sum((xi-x_bar)**2 for xi,_ in data)
b_hat = y_bar - w_hat * x_bar
print(simplify(w_hat), simplify(b_hat))   # 41/20, 19/20
