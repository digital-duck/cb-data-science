Heart Disease Classification

Definition. Heart disease classification is a supervised learning problem in which a model $f: \mathbb{R}^d \to \{0, 1\}$ maps a patient feature vector $\mathbf{x} = (x_1, x_2, \ldots, x_d)^\top$ to a binary label $y \in \{0, 1\}$, where $y = 1$ denotes the presence of coronary artery disease and $y = 0$ denotes its absence. The feature space typically includes clinical measurements such as age, resting blood pressure, serum cholesterol, maximum heart rate achieved, and the ST-segment depression induced by exercise. Formally, given a training set $\mathcal{D} = \{(\mathbf{x}^{(i)}, y^{(i)})\}_{i=1}^{n}$, the learning objective is to find $f$ that minimises expected classification error $\mathbb{E}[\mathbf{1}(f(\mathbf{x}) \neq y)]$ over the true data distribution.

Worked Example. Consider the Cleveland Heart Disease dataset, which contains $n = 303$ patient records with $d = 13$ features. After standardising each feature to zero mean and unit variance, one applies logistic regression, which models the conditional probability

$$P(y = 1 \mid \mathbf{x}) = \sigma(\mathbf{w}^\top \mathbf{x} + b) = \frac{1}{1 + e^{-(\mathbf{w}^\top \mathbf{x} + b)}},$$

where $\sigma(\cdot)$ is the sigmoid function. Parameters $\mathbf{w} \in \mathbb{R}^d$ and $b \in \mathbb{R}$ are estimated by maximising the log-likelihood

$$\ell(\mathbf{w}, b) = \sum_{i=1}^{n} \left[ y^{(i)} \log \hat{p}^{(i)} + (1 - y^{(i)}) \log(1 - \hat{p}^{(i)}) \right].$$

On a 70/30 train–test split, logistic regression achieves approximately 84% accuracy, with the ST-depression feature carrying the largest positive coefficient.

Key Theorem (Bayes Optimality). The classifier that minimises expected 0–1 loss is the Bayes classifier $f^*(\mathbf{x}) = \mathbf{1}(P(y=1 \mid \mathbf{x}) > \tfrac{1}{2})$. Any learning algorithm is evaluated by how closely its decision boundary approximates this optimal boundary. In class-imbalanced clinical settings, the decision threshold $\tau$ may be shifted below $\tfrac{1}{2}$ to increase sensitivity (recall for $y=1$) at the cost of specificity.

Lab Cell.

from sklearn.datasets import fetch_openml
from sklearn.linear_model import LogisticRegression
from sklearn.preprocessing import StandardScaler
from sklearn.model_selection import train_test_split
from sklearn.metrics import classification_report

data = fetch_openml("heart-disease", version=1, as_frame=True)
X, y = data.data.fillna(data.data.median()), (data.target.astype(int) > 0).astype(int)

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)
scaler = StandardScaler()
X_train_s = scaler.fit_transform(X_train)
X_test_s  = scaler.transform(X_test)

model = LogisticRegression(max_iter=1000)
model.fit(X_train_s, y_train)
print(classification_report(y_test, model.predict(X_test_s)))
