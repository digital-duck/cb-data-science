Sigmoid Function

You may have already heard that the sigmoid function "squishes" any number into the range between 0 and 1 — like a dimmer switch that turns any signal into a probability. That intuition is exactly right. Now let's look at the actual machinery behind it.

The sigmoid function is defined as:

$$\sigma(x) = \frac{1}{1 + e^{-x}}$$

Here $e \approx 2.718$ is Euler's number. When $x$ is a large positive number, $e^{-x}$ shrinks toward zero, so the denominator approaches $1 + 0 = 1$, giving $\sigma(x) \approx 1$. When $x$ is a large negative number, $e^{-x}$ explodes, making the denominator huge, so $\sigma(x) \approx 0$. At exactly $x = 0$:

$$\sigma(0) = \frac{1}{1 + e^{0}} = \frac{1}{1 + 1} = 0.5$$

This is the midpoint — the function is perfectly balanced at zero. The resulting curve is a smooth, symmetric S-shape called a logistic curve.

The key pattern: the sigmoid is monotone (always increasing) and bounded — no matter what you feed in, the output stays strictly between 0 and 1. This makes it ideal whenever you need a number to act like a probability or a confidence score.
