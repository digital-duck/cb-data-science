Decision Tree

Definition. A decision tree is a rooted, directed acyclic graph $T = (V, E)$ in which every internal node $v \in V_{\text{int}}$ is associated with a split function $\phi_v : \mathcal{X} \to \{1, \ldots, k_v\}$, each leaf $\ell \in V_{\text{leaf}}$ carries a prediction $\hat{y}_\ell \in \mathcal{Y}$, and every input $\mathbf{x} \in \mathcal{X}$ follows a unique root-to-leaf path determined by evaluating successive split functions. For axis-aligned binary trees — the most common case — each split function takes the form $\phi_v(\mathbf{x}) = \mathbf{1}[x_j \leq \theta]$ for some feature index $j$ and threshold $\theta \in \mathbb{R}$, partitioning the feature space $\mathcal{X} \subseteq \mathbb{R}^d$ into a collection of non-overlapping rectangular regions $R_1, \ldots, R_M$. The tree's prediction is then $f(\mathbf{x}) = \sum_{m=1}^{M} \hat{y}_m \,\mathbf{1}[\mathbf{x} \in R_m]$.

Worked Example. Consider a dataset of students with two features: study hours $x_1$ and prior GPA $x_2$, and a binary label $y \in \{0, 1\}$ (fail/pass). Suppose a depth-2 tree first splits on $x_1 \leq 3$: students studying three or fewer hours go left, the rest go right. The right branch then splits on $x_2 \leq 2.5$. This produces three leaf regions: $R_1 = \{x_1 \leq 3\}$, $R_2 = \{x_1 > 3,\, x_2 \leq 2.5\}$, and $R_3 = \{x_1 > 3,\, x_2 > 2.5\}$, with predictions $\hat{y} = 0, 0, 1$ respectively.

Key Theorem (CART Greedy Optimality). At each node $v$ containing sample set $S_v$, the CART algorithm selects the split $(j^, \theta^)$ minimising the weighted impurity reduction:

$$\Delta I(j,\theta) = I(S_v) - \frac{|S_L|}{|S_v|} I(S_L) - \frac{|S_R|}{|S_v|} I(S_R),$$

where $S_L, S_R$ are the left and right child subsets and $I$ denotes an impurity measure (Gini: $I(S) = 1 - \sum_c p_c^2$; entropy: $I(S) = -\sum_c p_c \log p_c$). Although this greedy criterion does not guarantee a globally optimal tree — finding the minimum-depth consistent tree is NP-hard — it yields strong empirical performance in $O(dn \log n)$ time per level.

Lab Cell.

from sympy import symbols, Piecewise, And

x1, x2 = symbols('x1 x2', real=True)

predict = Piecewise(
    (0, x1 <= 3),
    (0, And(x1 > 3, x2 <= 2.5)),
    (1, True)
)

# Evaluate for a student with x1=4, x2=3.0
print(predict.subs({x1: 4, x2: 3.0}))   # expected: 1

Running this cell confirms that the symbolic piecewise expression correctly encodes the tree's three decision regions, illustrating how a decision tree is, at its core, a structured partition of input space.
