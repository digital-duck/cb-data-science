Random Forest

Definition. A random forest is an ensemble learning method that constructs a collection of $B$ decision trees $\{T_1, T_2, \ldots, T_B\}$, each trained on a bootstrap sample of the training data, and aggregates their predictions by majority vote (classification) or averaging (regression). Two sources of randomness distinguish a random forest from a simple collection of trees: (1) bootstrap aggregation (bagging), in which each tree $T_b$ is fit to a resample $\mathcal{D}_b$ of size $n$ drawn with replacement from the original dataset $\mathcal{D}$; and (2) feature subsampling, in which each candidate split considers only a randomly chosen subset of $m \ll p$ features, where $p$ is the total number of predictors. The standard recommendation is $m = \lfloor\sqrt{p}\rfloor$ for classification and $m = \lfloor p/3 \rfloor$ for regression.

The final prediction for a new observation $\mathbf{x}$ is

$$\hat{f}(\mathbf{x}) = \frac{1}{B} \sum_{b=1}^{B} T_b(\mathbf{x}).$$

Worked example. Suppose $p = 9$ features and $B = 3$ trees. Each tree uses $m = \lfloor\sqrt{9}\rfloor = 3$ candidate features per split. Bootstrap sample $\mathcal{D}_1$ might omit observation 4 but include observation 7 twice; $\mathcal{D}_2$ omits observations 2 and 6; and so on. If trees $T_1, T_2$ predict class 1 and $T_3$ predicts class 0 for a test point, the ensemble vote yields class 1. The out-of-bag (OOB) error is estimated using each observation's predictions from trees that did not include it in their bootstrap sample, providing an unbiased validation estimate without a separate hold-out set.

Key theorem (variance reduction). If $B$ trees each have prediction variance $\sigma^2$ and pairwise correlation $\rho$, then the variance of the ensemble average satisfies

$$\operatorname{Var}\!\left(\hat{f}\right) = \rho\,\sigma^2 + \frac{1 - \rho}{B}\,\sigma^2.$$

As $B \to \infty$, the second term vanishes and variance is bounded below by $\rho\,\sigma^2$. Feature subsampling reduces $\rho$, yielding a lower floor than bagging alone.

Lab cell.

from sklearn.datasets import load_iris
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import cross_val_score
import numpy as np

X, y = load_iris(return_X_y=True)
rf = RandomForestClassifier(n_estimators=200, max_features="sqrt",
                            oob_score=True, random_state=42)
rf.fit(X, y)

print(f"OOB accuracy : {rf.oob_score_:.3f}")
cv_acc = cross_val_score(rf, X, y, cv=5).mean()
print(f"5-fold CV    : {cv_acc:.3f}")
importances = rf.feature_importances_
for name, imp in zip(load_iris().feature_names, importances):
    print(f"  {name:<25s} {imp:.3f}")

Running this cell reveals that petal length and petal width dominate feature importance, consistent with the known separability structure of the Iris dataset.
