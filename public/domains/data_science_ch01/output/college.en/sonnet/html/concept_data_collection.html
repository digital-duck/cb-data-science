Data Collection

Definition. Data collection is the systematic process of gathering observations from a population or process in accordance with a pre-specified protocol, such that each recorded value can be associated with a measurable quantity, a unit of measurement, and a source. Formally, if $\Omega$ denotes the sample space of all possible outcomes, a data collection procedure defines a measurable function $X : \Omega \to \mathbb{R}^d$ together with an index set $\mathcal{I}$ of observation timestamps or identifiers. The result is a dataset $\mathcal{D} = \{(i, \mathbf{x}_i) : i \in \mathcal{I},\; \mathbf{x}_i \in \mathbb{R}^d\}$.

A collection procedure is called well-posed if it satisfies three properties: (1) reproducibility — independent repetitions under identical conditions yield statistically equivalent samples; (2) traceability — every datum can be traced to its instrument, timestamp, and operator; and (3) representativeness — the sample distribution approximates the target population distribution within a stated tolerance.

Worked Example. Suppose a laboratory measures the boiling point of water at varying altitudes. At altitude $h_i$ (in metres), the atmospheric pressure follows $P_i \approx 101{,}325 \cdot e^{-h_i/8500}$ Pa. An experimenter records $n = 5$ paired observations:

$$\mathcal{D} = \{(h_i,\, T_i)\}_{i=1}^{5} = \{(0, 100.0),\, (500, 98.3),\, (1000, 96.7),\, (1500, 95.0),\, (2000, 93.4)\}$$

where $T_i$ is in degrees Celsius. Each entry is traceable to a calibrated thermometer ($\pm 0.1\,^\circ\text{C}$) and a GPS altimeter ($\pm 5\,\text{m}$), satisfying the traceability requirement.

Key Theorem (Law of Large Numbers — Weak Form). Let $X_1, X_2, \ldots, X_n$ be independent, identically distributed random variables with finite mean $\mu = \mathbb{E}[X_1]$. Then the sample mean $\bar{X}_n = \frac{1}{n}\sum_{i=1}^n X_i$ converges in probability to $\mu$:

$$\bar{X}_n \xrightarrow{P} \mu \quad \text{as } n \to \infty.$$

This theorem provides the theoretical justification for increasing sample size to improve accuracy: systematic collection of more observations reduces the gap between observed statistics and true population parameters.

Lab Cell (SymPy).

from sympy import symbols, exp, lambdify, Rational
import numpy as np

h = symbols('h', positive=True)
P = 101325 * exp(-h / 8500)          # atmospheric pressure model
P_func = lambdify(h, P, 'numpy')

altitudes = np.array([0, 500, 1000, 1500, 2000])
pressures = P_func(altitudes)
T_boil    = 100 - (101325 - pressures) / 3600   # linear approximation

for hi, Ti in zip(altitudes, T_boil):
    print(f"h = {hi:5d} m  →  T_boil ≈ {Ti:.2f} °C")

Running this cell reproduces the dataset $\mathcal{D}$ analytically, demonstrating how a physical model and a collection protocol together define a self-consistent, traceable experiment.
