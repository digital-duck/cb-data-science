Concept Book: Recommendation System

Data Science Ch01 · Generated by SPL

Payoff

A recommendation system is a function $f: \mathcal{U} \times \mathcal{I} \to \mathbb{R}$ that assigns a predicted relevance score to each user–item pair $(u, i) \in \mathcal{U} \times \mathcal{I}$, where $\mathcal{U}$ is a finite set of users and $\mathcal{I}$ is a finite set of items. Given observed ratings $R \in \mathbb{R}^{|\mathcal{U}| \times |\mathcal{I}|}$ (sparse, with most entries unknown), the system learns $f$ so that for any user $u$ the ranked list $\arg\!\top_k\{f(u,i) : i \notin \text{observed}(u)\}$ surfaces the $k$ items most likely to be valued.

This is the natural endpoint of the concept-book's journey because every mathematical structure encountered along the way—linear algebra, probability, optimization, and graph theory—converges here. Matrix factorization decomposes $R \approx P Q^\top$ where $P \in \mathbb{R}^{|\mathcal{U}| \times d}$ and $Q \in \mathbb{R}^{|\mathcal{I}| \times d}$ are latent-factor matrices learned by minimizing the regularized loss

$$\mathcal{L}(P, Q) = \sum_{(u,i)\in\Omega} \bigl(R_{ui} - \mathbf{p}_u^\top \mathbf{q}_i\bigr)^2 + \lambda\bigl(\|P\|_F^2 + \|Q\|_F^2\bigr),$$

where $\Omega$ is the set of observed entries and $\|\cdot\|_F$ denotes the Frobenius norm. Gradient descent on $\mathcal{L}$ simultaneously encodes user preference and item character into $d$-dimensional vectors, making the dot product $\mathbf{p}_u^\top \mathbf{q}_i$ a geometric measure of affinity.

Worked example. Suppose $|\mathcal{U}| = 4$, $|\mathcal{I}| = 5$, and $d = 2$. After convergence, user $u_1$ has latent vector $\mathbf{p}_1 = (0.9, 0.2)$ and items $i_2, i_4$ have vectors $(0.8, 0.3)$ and $(0.1, 0.9)$, respectively. Then $\mathbf{p}_1^\top \mathbf{q}_2 = 0.78$ and $\mathbf{p}_1^\top \mathbf{q}_4 = 0.27$, so item $i_2$ ranks first for user $u_1$—a concise decision extracted from partial data.

Theorem (Eckart–Young–Mirsky). Among all rank-$d$ approximations $\hat{R}$ of $R$, the truncated singular value decomposition $\hat{R} = U_d \Sigma_d V_d^\top$ minimizes $\|R - \hat{R}\|_F^2$. This guarantees that matrix factorization captures the maximum possible variance in user–item interactions within a fixed latent dimension $d$.

import sympy as sp

R = sp.Matrix([
    [5, 3, 0, 1],
    [4, 0, 0, 1],
    [1, 1, 0, 5],
    [1, 0, 0, 4],
])

# Compute SVD symbolically (numeric for speed)
import numpy as np
U, s, Vt = np.linalg.svd(R.tolist(), full_matrices=False)
d = 2
R_hat = U[:, :d] @ np.diag(s[:d]) @ Vt[:d, :]
print(np.round(R_hat, 2))   # rank-2 reconstruction

The recommendation system therefore stands as a unifying lens: collaborative filtering generalizes nearest-neighbour search, the regularized objective instantiates constrained optimization, and the latent space interprets eigenvectors as human preference. Extend this framework to streaming content platforms and the same algebra drives real-time personalisation at scale; apply it to e-commerce and it becomes an engine of discovery for long-tail products that users would never have found unaided.

You are invited to choose one domain and pursue it in depth—trace how the loss function must be modified when implicit feedback (clicks, dwell-time) replaces explicit ratings, or how graph-based propagation through user–item bipartite networks enriches the latent factors beyond what matrix factorization alone can capture.
