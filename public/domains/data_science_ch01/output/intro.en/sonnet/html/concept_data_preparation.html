Data Preparation

Definition. Data preparation is the process of transforming a raw dataset $\mathcal{D}_{\text{raw}} = \{(\mathbf{x}_i, y_i)\}_{i=1}^{N}$ into a clean, numerically suitable form $\mathcal{D}_{\text{clean}}$ prior to model training or statistical analysis. The transformation pipeline typically comprises four stages: (1) missing-value imputation, (2) outlier handling, (3) feature scaling, and (4) train–test partitioning. Each stage is a deterministic or probabilistic map applied in sequence, so the composition is itself a map $\phi: \mathcal{D}_{\text{raw}} \to \mathcal{D}_{\text{clean}}$.

Formally, let $\mathbf{X} \in \mathbb{R}^{N \times p}$ denote the feature matrix with $N$ observations and $p$ features. Min–max scaling of column $j$ produces

$$\tilde{x}_{ij} = \frac{x_{ij} - \min_i x_{ij}}{\max_i x_{ij} - \min_i x_{ij}} \in [0, 1],$$

while z-score standardization centers and scales to unit variance:

$$\tilde{x}_{ij} = \frac{x_{ij} - \mu_j}{\sigma_j}, \quad \mu_j = \frac{1}{N}\sum_{i=1}^N x_{ij},\quad \sigma_j = \sqrt{\frac{1}{N}\sum_{i=1}^N (x_{ij}-\mu_j)^2}.$$

Worked Example. Suppose $\mathbf{x} = (2, \text{NaN}, 8, 14)^{\top}$ represents four temperature readings. After mean imputation the vector becomes $\mathbf{x}' = (2, 8, 8, 14)^{\top}$ (mean of the three observed values equals $8$). Applying min–max scaling with $\min = 2$, $\max = 14$ gives $\tilde{\mathbf{x}} = (0,\ 0.5,\ 0.5,\ 1)^{\top}$, confirming all entries lie in $[0,1]$.

Key Theorem (Leakage-Free Partitioning). All scaling statistics ($\mu_j$, $\sigma_j$, min, max) must be estimated exclusively on the training split and then applied to the validation and test splits. Fitting statistics on the full dataset introduces data leakage, causing optimistic bias in generalization error estimates and invalidating held-out evaluation.

Lab Cell.

from sympy import Matrix, Rational, symbols, sqrt

x = Matrix([2, 8, 8, 14])          # after imputation
mu = x.mean()                       # = 8
sigma = sqrt(sum((v - mu)**2 for v in x) / len(x))
z = Matrix([(v - mu) / sigma for v in x])
print("z-scores:", z.T)             # [-sqrt(6)/2, 0, 0, sqrt(6)/2]

Running this cell confirms the z-scores are exact symbolic rationals, illustrating that data preparation is amenable to computer-algebra verification before any floating-point computation begins.
