Internet Of Things

Definition. The Internet of Things (IoT) is a networked system of physical devices — sensors, actuators, and embedded processors — that collect, transmit, and act upon data without continuous human intervention. Formally, an IoT system can be modeled as a directed graph $G = (V, E)$, where each vertex $v_i \in V$ represents a device with an associated state vector $\mathbf{s}_i(t) \in \mathbb{R}^d$, and each directed edge $(v_i, v_j) \in E$ represents a communication channel with latency $\ell_{ij} \geq 0$ and bandwidth $b_{ij} > 0$. A gateway node aggregates streams from sensor nodes and routes them to a cloud or edge-computing layer for storage and analysis.

Worked Example. Consider a smart-agriculture deployment with three soil-moisture sensors $v_1, v_2, v_3$ and one irrigation actuator $v_4$. Each sensor reports moisture level $m_i(t) \in [0, 1]$ every $\Delta t = 60$ seconds. A central controller computes the mean field

$$\bar{m}(t) = \frac{1}{3}\sum_{i=1}^{3} m_i(t)$$

and triggers irrigation when $\bar{m}(t) < \theta = 0.3$. If sensor readings at time $t = 0$ are $m_1 = 0.25$, $m_2 = 0.28$, $m_3 = 0.35$, then $\bar{m}(0) = 0.293 < 0.3$, so the actuator fires. This threshold-crossing logic exemplifies event-driven control, the dominant paradigm in IoT firmware.

Key Theorem (Nyquist–Shannon Sampling for IoT). Let a physical process $x(t)$ be bandlimited with maximum frequency $f_{\max}$. A sensor sampling at rate $f_s$ reconstructs $x(t)$ exactly if and only if

$$f_s > 2f_{\max}.$$

In practice, IoT designers apply a safety margin $f_s \geq 2.5\, f_{\max}$ to account for anti-aliasing filter roll-off, ensuring that the discrete time series $\{x(k\Delta t)\}$ faithfully represents the underlying continuous phenomenon.

Lab Cell.

import sympy as sp

t, f_s, f_max = sp.symbols('t f_s f_max', positive=True)

# Nyquist condition
nyquist = sp.Gt(f_s, 2 * f_max)
print("Nyquist condition:", nyquist)

# Mean-field threshold check
m = [0.25, 0.28, 0.35]
m_bar = sp.Rational(sum(int(v * 100) for v in m), 300)
theta = sp.Rational(3, 10)
print("Mean moisture:", m_bar, "| Irrigate?", m_bar < theta)

Running this cell confirms $\bar{m} = \tfrac{88}{300} \approx 0.293 < 0.3$, matching the worked example analytically.
