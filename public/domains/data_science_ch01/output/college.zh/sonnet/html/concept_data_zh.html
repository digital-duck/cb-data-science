数据

数据是对现实世界中某个对象或现象所做的可记录、可传递的观测结果。它可以是数字（某城市当天的气温为 $28\,^\circ\text{C}$）、类别（一位用户选择了"蓝色"）或文本（一条评论）。数据本身没有意义——意义来自于对数据的组织、解读和分析。理解数据的关键是区分两个维度：数据类型（定量 vs. 定性）和数据结构（结构化 vs. 非结构化）。定量数据可以直接参与数学运算，定性数据则需要编码或分类后才能分析。

实例：学生成绩表

假设你收集了一个班级 5 位同学的数学期末成绩：

| 学生 | 成绩 | |------|------| | 小明 | 88 | | 小红 | 92 | | 小华 | 75 | | 小丽 | 95 | | 小强 | 83 |

这是一张结构化定量数据表。你可以立刻计算平均分：

$$\bar{x} = \frac{88 + 92 + 75 + 95 + 83}{5} = \frac{433}{5} = 86.6$$

但如果你想知道"哪位同学进步最大"，光有期末成绩还不够——你还需要期初成绩，这说明数据的完整性和上下文同样重要。

解题应用：数据清洗与分析

现实数据往往不干净。设你从问卷中收到以下年龄填写结果：[21, 19, "二十岁", None, 300, 22]。

要分析这组数据，你需要：

  • 识别异常值：300 明显不合理，属于录入错误，应剔除或标记。
  • 处理缺失值：None 表示未填写，可以用均值填补，或直接排除该条记录。
  • 统一格式："二十岁" 是文本，需转换为数字 20 才能参与运算。

    • 清洗后的数据为 [21, 19, 20, 22]，均值为

    $$\bar{x} = \frac{21+19+20+22}{4} = 20.5$$

    这个流程揭示了数据处理的核心原则：先理解数据的来源和质量，再进行任何计算。一个错误的数据点比没有数据更危险，因为它会让结论看起来可信，却指向错误的方向。
