Data Preparation

You've probably heard the phrase "garbage in, garbage out." Before any algorithm can learn from data, the data itself has to be clean, organized, and in the right shape. This step — data preparation — is where most of the real work in machine learning actually lives.

The structure underneath the cleanup

Raw data collected from the world is almost always messy. It might have missing values (a survey respondent skipped a question), inconsistent formats ("New York," "new york," and "NY" all mean the same thing), or wildly different scales (one column holds ages in the range 0–100, another holds income in the range 0–200,000).

That scale problem matters more than it looks. Many learning algorithms compute distances or weighted sums. If income is 2,000 times larger than age by raw units, it will dominate every calculation — not because it's more important, but just because its numbers are bigger.

The key rule: normalization and encoding

Two transformations come up constantly:

  • Min-max normalization rescales every value to the interval $[0, 1]$:
    • $$x' = \frac{x - x_{\min}}{x_{\max} - x_{\min}}$$
  • One-hot encoding converts a category like {red, green, blue} into three binary columns: $(1,0,0)$, $(0,1,0)$, $(0,0,1)$. Numbers don't imply order; binary flags don't.

    • Together these two rules put every feature on equal footing before learning begins.

    Practice problem

    A dataset has one column of exam scores: $\{40, 60, 80, 100\}$. Apply min-max normalization to produce the rescaled values. What does the score 60 become after the transformation?
