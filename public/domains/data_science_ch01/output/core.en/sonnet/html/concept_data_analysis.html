Data Analysis

You already know that data is just a collection of observations — temperatures recorded each day, test scores in a class, or the number of steps you walk. Data analysis is what happens next: turning that raw list of numbers into something you can understand and use.

The first move is almost always to summarize. Given a dataset $\{x_1, x_2, \ldots, x_n\}$, two summaries immediately tell you a lot:

  • Mean (the balance point): $\bar{x} = \dfrac{1}{n}\sum_{i=1}^{n} x_i$
  • Range (the spread): $R = x_{\max} - x_{\min}$

    • These two numbers together already reveal whether values are tightly packed around a typical value or wildly scattered. A class where everyone scores between 78 and 82 is very different from one where scores run from 45 to 99 — even if the means are identical.

    The next layer is distribution: how often does each value (or range of values) appear? A histogram groups data into bins and lets you see the shape — is it symmetric, skewed to one side, or does it have two humps? Shape matters because it tells you whether the mean is a fair representative or misleading.

    A simple pattern to remember: mean describes center; spread and shape describe context. Never report one without at least hinting at the other.
