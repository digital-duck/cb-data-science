Concept Book: Augmented Dickey Fuller Test

Data Science Ch05 · Generated by SPL

收益

在本书的最后，我们来回答一个问题：学完增广迪基-富勒检验（augmented Dickey–Fuller test，ADF 检验），我们究竟获得了什么能力？答案是：用数据本身判断一个时间序列是否"平稳"，并据此决定后续建模该怎么做。

它解决了什么问题

考虑自回归模型 $y_t = \rho\, y_{t-1} + \varepsilon_t$。若 $|\rho|<1$，序列围绕固定均值波动，是平稳的。若 $\rho = 1$，序列是随机游走，冲击永久残留，方差随时间增长。两种情形在图上常常难以分辨，却会导致完全不同的预测结论。

ADF 检验将上式改写为差分形式：

$$\Delta y_t = \alpha + \beta t + \gamma\, y_{t-1} + \sum_{i=1}^{p} \delta_i\, \Delta y_{t-i} + \varepsilon_t,\qquad \gamma = \rho - 1.$$

原假设 $H_0:\gamma = 0$（存在单位根，非平稳），备择假设 $H_1:\gamma<0$（平稳）。滞后差分项 $\Delta y_{t-i}$ 用来吸收残差的序列相关，这就是"增广"的含义。关键一点：在 $H_0$ 下，$\hat\gamma$ 的 $t$ 统计量不服从标准 $t$ 分布，必须与迪基-富勒临界值比较。

为什么它是自然的终点

它汇集了前面各章的内容：回归与假设检验提供框架，自回归模型提供对象，差分与滞后算子提供变换，渐近分布提供临界值。它也是通向实际建模的入口，因为多数时间序列方法都以平稳性为前提。

一个简短的应用示例

from statsmodels.tsa.stattools import adfuller
stat, pvalue, *_ = adfuller(series, regression="ct", autolag="AIC")

若 $p$ 值小于 0.05，则拒绝单位根，可直接建模。否则先取一阶差分 $\Delta y_t$，再次检验。

与应用领域的联系

本节没有列出具体的应用领域，所以下面只给出这一检验通常出现的几类场景。具体清单请以你的课程为准。

  • 金融与经济：价格序列通常有单位根，而收益率通常平稳。ADF 检验帮助我们决定是对价格建模还是对收益率建模。
  • 协整与配对交易：若两个非平稳序列的某个线性组合平稳，二者就存在长期均衡关系。检验这个组合的残差，是 Engle–Granger 方法的核心步骤。
  • 预测模型（ARIMA）：差分阶数 $d$ 通常由反复进行单位根检验来确定。
  • 避免伪回归：对两个互不相关的随机游走做回归，常会得到很高的 $R^2$ 和"显著"的系数。检验平稳性可以防止这种误判。

    • 注意事项

    ADF 检验的检验功效有限。当 $\rho$ 接近 1 时，它很难拒绝原假设，因此结论应结合 KPSS 等原假设相反的检验一起判断。
