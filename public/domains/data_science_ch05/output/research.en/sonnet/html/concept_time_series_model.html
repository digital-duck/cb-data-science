Time Series Model

Definition. A time series is a sequence of observations $\{x_t\}_{t=1}^{T}$ indexed by discrete time $t \in \mathbb{Z}$; this section takes that notion as given and introduces its single new object: the autoregressive model of order $p$, denoted $\mathrm{AR}(p)$:

$$x_t = \phi_1 x_{t-1} + \phi_2 x_{t-2} + \cdots + \phi_p x_{t-p} + \varepsilon_t, \qquad \varepsilon_t \overset{\text{i.i.d.}}{\sim} \mathcal{N}(0, \sigma^2),$$

where $\phi_1, \ldots, \phi_p \in \mathbb{R}$ are autoregressive coefficients and $\varepsilon_t$ is white noise. The model asserts that the present value is a linear combination of the $p$ most recent values plus an unpredictable shock. When all the statistical properties of $x_t$ depend only on the time gap between observations—not on the calendar time itself—the process is said to be weakly stationary, a prerequisite for the coefficient estimates to carry meaning.

Worked Example. Consider the $\mathrm{AR}(1)$ process $x_t = 0.8\, x_{t-1} + \varepsilon_t$ with $\sigma^2 = 1$ and $x_0 = 0$. Taking expectations of both sides, stationarity requires $\mu = 0.8\mu$, so $\mu = 0$. The variance satisfies $\mathrm{Var}(x_t) = \sigma^2/(1 - 0.8^2) \approx 2.78$, and the correlation between $x_t$ and $x_{t-k}$ equals $0.8^k$. At lag $k = 3$ this correlation is $0.512$, indicating substantial serial dependence three steps ahead—precisely the structure the $\mathrm{AR}(1)$ model encodes.

Theorem (Stationarity of $\mathrm{AR}(p)$). The $\mathrm{AR}(p)$ process is weakly stationary if and only if all roots of the characteristic polynomial

$$\Phi(z) = 1 - \phi_1 z - \phi_2 z^2 - \cdots - \phi_p z^p$$

lie strictly outside the unit circle, $|z| > 1$, in the complex plane. For the $\mathrm{AR}(1)$ case this reduces to $|\phi_1| < 1$, consistent with the example above where $|\phi_1| = 0.8$.

import numpy as np
from sympy import symbols, Rational, Abs, solve

phi = Rational(4, 5)          # 0.8 as exact fraction
z   = symbols('z')
char_poly = 1 - phi * z
roots = solve(char_poly, z)   # [5/4]
print("Root:", roots, "  |root| > 1:", Abs(roots[0]) > 1)

# Simulate AR(1) numerically
rng  = np.random.default_rng(42)
T    = 200
x    = np.zeros(T)
eps  = rng.normal(0, 1, T)
for t in range(1, T):
    x[t] = 0.8 * x[t-1] + eps[t]
print("Sample mean:", x.mean().round(3), " Sample var:", x.var().round(3))
