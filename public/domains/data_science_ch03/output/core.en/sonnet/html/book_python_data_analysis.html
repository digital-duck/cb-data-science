Payoff

You have spent this book building a toolkit — variables that remember values, loops that repeat tasks, functions that package logic, and lists that hold collections of data. Now those tools click together into something genuinely powerful: Python data analysis, the practice of loading real-world numbers, computing patterns across them, and communicating what you find.

Here is why this is the natural endpoint. A single number rarely means much. The temperature right now is just a fact. But a table of temperatures recorded every hour for a year becomes a story — about seasons, about climate, about whether this summer was unusual. Python lets you read that table, ask questions of it, and answer them with mathematics. The core workflow looks like this:

$$\bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i$$

That formula — the mean — is something you already know. What Python adds is the ability to compute it over thousands of rows in a single line, slice the data by category, and plot the result, all without a spreadsheet.

Even with no applications explicitly listed for this book, the doors that open are immediate: you can analyze your school's test-score trends, explore weather records from your city, or investigate how streaming songs correlate with chart position. Each of those projects uses the same three moves — load, summarize, visualize — that you have now practiced.

Practice problem. Download (or copy-paste) a small CSV file containing at least 20 numbers in one column — daily steps, quiz scores, anything you like. Write a Python script that prints the mean, the maximum, and the minimum. Then add one print statement that tells you whether the mean is closer to the max or to the min.
