Python Data Analysis

Quick recap: You already know that data is everywhere — scores, temperatures, prices, populations. Python gives you tools to talk to that data systematically instead of staring at a spreadsheet.

The structure beneath the surface

Real data analysis follows a repeatable pipeline:

  • Load — read data from a file (CSV, Excel, database)
  • Inspect — check shape, types, and missing values
  • Clean — fix errors, fill gaps, standardize formats
  • Analyze — compute summaries, find patterns
  • Visualize — turn numbers into pictures

    • The two workhorses are pandas (data tables) and matplotlib/seaborn (charts). A pandas DataFrame is like a spreadsheet in code — rows are observations, columns are variables.

    import pandas as pd

df = pd.read_csv("scores.csv")
print(df.shape)        # (rows, columns)
print(df.describe())   # count, mean, std, min, max per column

    The describe() method gives you the five-number summary plus mean and standard deviation in one call. For a column of exam scores, the mean $\bar{x} = \frac{1}{n}\sum_{i=1}^n x_i$ and standard deviation $s$ tell you the center and spread immediately.

    Filtering rows works like a math predicate:

    high_scorers = df[df["score"] > 90]

    This keeps only the rows where the condition is True — exactly like set-builder notation $\{x \mid x > 90\}$.

    The rule to remember: every analysis step maps to one clear action: load → inspect → clean → analyze → visualize. Skip a step and your conclusions may be built on messy data.

    Practice problem: Download any small CSV (weather data, sports stats, your own grade sheet). Load it with pandas, print df.describe(), and answer: Which column has the highest standard deviation, and what does that tell you about the variability in that variable?
