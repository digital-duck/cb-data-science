Python Statistical Computing

Definition. Python statistical computing refers to the implementation of probabilistic and statistical algorithms in the Python ecosystem—primarily via NumPy, SciPy, and statsmodels—where mathematical operations on random variables, estimators, and probability distributions are realized as vectorized array computations. The central object is the $n \times p$ data matrix $\mathbf{X} \in \mathbb{R}^{n \times p}$, and the fundamental computational primitive is the BLAS/LAPACK-backed matrix routine invoked through numpy.linalg or scipy.linalg. The discipline is not merely applied statistics with a Python flavor; it encompasses a nontrivial intersection of floating-point arithmetic, algorithmic complexity, and the asymptotic theory of estimators.

Theorem and Derivation. Consider the ordinary least-squares estimator $\hat{\boldsymbol{\beta}} = (\mathbf{X}^\top \mathbf{X})^{-1} \mathbf{X}^\top \mathbf{y}$. In exact arithmetic this is a closed-form expression, but in finite-precision computation the numerical stability depends critically on the condition number $\kappa(\mathbf{X}^\top \mathbf{X}) = \kappa(\mathbf{X})^2$. If $\mathbf{X}$ has singular values $\sigma_1 \geq \cdots \geq \sigma_p > 0$, then the relative forward error in $\hat{\boldsymbol{\beta}}$ satisfies

$$\frac{\|\delta\hat{\boldsymbol{\beta}}\|}{\|\hat{\boldsymbol{\beta}}\|} \lesssim \kappa(\mathbf{X})^2 \cdot \epsilon_{\text{mach}},$$

where $\epsilon_{\text{mach}} \approx 2.2 \times 10^{-16}$ for IEEE 754 double precision. The standard remedy is to compute $\hat{\boldsymbol{\beta}}$ via the QR decomposition $\mathbf{X} = \mathbf{Q}\mathbf{R}$, reducing the effective condition number to $\kappa(\mathbf{X})$ rather than $\kappa(\mathbf{X})^2$. In Python, numpy.linalg.lstsq invokes the LAPACK routine _gelsd, which uses a divide-and-conquer SVD and therefore achieves the optimal error bound $O(\kappa(\mathbf{X})\epsilon_{\text{mach}})$ at cost $O(np^2)$. The distinction between these approaches is not academic: for design matrices with $\kappa(\mathbf{X}) \sim 10^8$, the naive normal-equation route loses all significance in double precision.

Literature Context. The foundational numerical analysis is laid out in Golub and Van Loan (Matrix Computations, 4th ed.) and Higham (Accuracy and Stability of Numerical Algorithms). The statistical side—how numerical error propagates into confidence intervals and hypothesis tests—is less thoroughly treated. Longley (1967) gave an early empirical study of ill-conditioning in econometric data; more recent work by McCullough and Vinod (1999) benchmarked statistical packages against certified reference datasets, finding substantial variation. Open questions remain: the interaction between regularization (ridge, LASSO) and numerical precision for correlated predictors in high dimensions is not fully characterized, and the behavior of iterative solvers (conjugate gradient, LSQR) relative to direct factorization for large sparse statistical problems is an active area.

Suggested Investigation. Generate a family of design matrices $\mathbf{X}_k$ with condition numbers $\kappa_k = 10^k$ for $k = 1, \ldots, 14$ (using controlled SVD construction) and compare the forward error of four solvers: (1) explicit normal equations via numpy.linalg.solve, (2) numpy.linalg.lstsq, (3) scipy.linalg.lstsq with lapack_driver='gelsy', and (4) iterative scipy.sparse.linalg.lsqr. Measure error against a reference solution computed in 128-bit arithmetic via Python's mpmath. Plot $\log_{10}(\text{relative error})$ against $\log_{10}(\kappa)$ and verify the theoretical slopes of $2$ and $1$ for the two regimes.

Report-writing note. A write-up of this investigation should establish: the theoretical error bounds with derivation, a reproducible code artifact for generating the test matrices, tables of empirical slopes with confidence intervals across repeated trials, and a practical recommendation for which scipy.linalg driver to use as a function of $n$, $p$, and estimated $\kappa(\mathbf{X})$. The report should also compare results against the certified reference values from NIST StRD (Statistical Reference Datasets), which provide ground-truth benchmarks for exactly this purpose.
