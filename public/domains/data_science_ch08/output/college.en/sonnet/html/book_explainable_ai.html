What Explainable AI Achieves

A machine learning model $f : \mathcal{X} \to \mathcal{Y}$ maps inputs to outputs, but in many high-stakes settings the mapping alone is insufficient. Explainable AI (XAI) is the discipline of constructing auxiliary functions $e : \mathcal{X} \times f \to \mathcal{E}$ that translate a model's internal computation into human-interpretable certificates, attributions, or logical rules. Formally, we say $e$ is a faithful explanation of $f$ at point $x_0$ if it satisfies a local fidelity condition: for every perturbation $\delta$ within a neighbourhood $B_\varepsilon(x_0)$,

$$\bigl|f(x_0 + \delta) - \hat{f}_{e}(x_0 + \delta)\bigr| \leq \tau,$$

where $\hat{f}_e$ is the interpretable surrogate induced by $e$ and $\tau$ is a prescribed tolerance. Explainable AI is the natural endpoint of this textbook because every concept developed here — symbolic logic, proof systems, probabilistic reasoning, and neural computation — converges on the same question: not merely what a system concludes, but why.

Worked Example

Consider a gradient-boosted classifier trained on clinical data to predict sepsis risk. The model achieves 91 % AUC yet a clinician cannot act on a raw probability score. Applying SHAP (SHapley Additive exPlanations), we decompose the prediction for patient $i$ as

$$f(x_i) = \phi_0 + \sum_{j=1}^{p} \phi_j,$$

where $\phi_0$ is the base-rate expectation and each $\phi_j \in \mathbb{R}$ quantifies the marginal contribution of feature $j$. For a patient with elevated lactate ($\phi_{\text{lactate}} = +0.18$) and normal white-cell count ($\phi_{\text{WBC}} = -0.04$), the decomposition pinpoints lactate as the primary alarm — a finding a clinician can immediately verify and act upon.

Key Theorem

Shapley Efficiency. The unique additive feature-attribution method satisfying efficiency ($\sum_j \phi_j = f(x) - f(\emptyset)$), symmetry, dummy, and linearity axioms is given by the Shapley value

$$\phi_j = \sum_{S \subseteq \mathcal{F} \setminus \{j\}} \frac{|S|!\,(p - |S| - 1)!}{p!}\bigl[f(S \cup \{j\}) - f(S)\bigr].$$

This result, grounded in cooperative game theory, guarantees that credit is distributed fairly across all features — providing a rigorous foundation for every attribution map this framework produces.

Lab Cell

import shap, numpy as np
from sklearn.ensemble import GradientBoostingClassifier

X, y = shap.datasets.adult()
model = GradientBoostingClassifier(n_estimators=100).fit(X, y)

explainer = shap.Explainer(model, X)
shap_values = explainer(X[:200])

shap.plots.beeswarm(shap_values)   # global feature importance
shap.plots.waterfall(shap_values[0])  # single-instance breakdown

Run this cell and observe how every prediction decomposes into a signed, summable attribution across features — the symbolic and numerical threads of this book rendered visible in a single plot.

Invitation

The clinical sepsis example is only one thread. The same Shapley machinery applies wherever a black-box must be audited: credit scoring under fair-lending law, autonomous vehicle perception, or scientific discovery pipelines where a model's reasoning must be reproduced by a peer. Choose any one of these domains and ask: Which features drive the decision, and does that align with domain knowledge? That question is the doorway into your first original investigation in explainable AI.
