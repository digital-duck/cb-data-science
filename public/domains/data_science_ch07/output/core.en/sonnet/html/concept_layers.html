Layers

You have probably heard that a neural network is "deep" because it has many layers. But what is a layer, really — and why does stacking them matter?

Think of each layer as one transformation step: it takes the numbers coming in, mixes them using learned weights, and passes the result forward. One layer can catch a simple pattern; stack several, and each one learns to recognize features built on top of what the previous layer found — edges early on, shapes in the middle, objects by the end.

The key new object here is the weight matrix $W^{(l)}$. If the previous layer produced a vector $\mathbf{a}^{(l-1)}$, then layer $l$ starts by computing

$$W^{(l)}\,\mathbf{a}^{(l-1)}$$

That matrix–vector product is what "mixing" means precisely: each row of $W^{(l)}$ takes a dot product with the incoming vector and produces one output number. (Layers also add a small shift and pass the result through a bending function before sending it on, but the weight matrix is the engine of the transformation.)

Because $W^{(l)}$ has shape $(\text{output size} \times \text{input size})$, it can change how many numbers flow to the next layer. One rule follows immediately: the output size of layer $l$ must equal the input size of layer $l+1$. Mismatched dimensions are the most common error when building a network by hand.

Practice. A network has three layers: layer 1 maps $4 \to 8$, layer 2 maps $8 \to 8$, layer 3 maps $8 \to 2$. Write the shape (rows $\times$ columns) of $W^{(l)}$ for each layer. How many total weight entries are there across all three layers?
