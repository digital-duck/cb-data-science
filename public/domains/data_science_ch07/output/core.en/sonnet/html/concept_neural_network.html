Neural Network

You've probably heard that neural networks are "inspired by the brain." True — but let's look past the metaphor at what they actually do.

The structure. A neural network is organized into layers: an input layer (say, pixel brightness values from an image), one or more hidden layers in between, and an output layer that produces a prediction (say, "cat" or "dog"). Each layer is made of neurons, and each neuron runs the same simple computation.

The one new idea. Here it is: a neuron takes a weighted sum of its inputs, adds a constant called a bias, and passes the result through an activation function. With two inputs $x_1$ and $x_2$:

$$z = w_1 x_1 + w_2 x_2 + b$$

Then the neuron's output is $a = f(z)$. The activation function used almost everywhere today is ReLU: $f(z) = \max(0,\, z)$. If $z$ is negative, the neuron outputs 0; if $z$ is positive, it passes $z$ through unchanged.

The simple rule. Everything interesting in a neural network comes from stacking many of these neurons together. The weights $w_i$ and biases $b$ are the numbers the network gradually adjusts as it sees more and more examples — all of the network's "knowledge" lives in them.

Practice problem. A neuron has inputs $x_1 = 3$ and $x_2 = -1$, weights $w_1 = 0.5$ and $w_2 = 2$, and bias $b = 1$. Compute $z$. Then apply ReLU. What is the neuron's output $a$?
