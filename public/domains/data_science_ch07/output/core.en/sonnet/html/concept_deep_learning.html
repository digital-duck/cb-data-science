Deep Learning

You already know that a single artificial neuron takes inputs, weights them, adds a bias, and passes the result through an activation function. Deep learning's central idea is to stack many such layers so that each one learns increasingly abstract features — early layers spot edges and short patterns, later layers combine those into shapes, then objects, then full concepts.

The structure to focus on is the feedforward layer. When a layer receives $n$ inputs packed into a vector $\mathbf{x}$, its learned weights form a matrix $W$ and its biases a vector $\mathbf{b}$. The layer computes:

$$\mathbf{a} = f(W\mathbf{x} + \mathbf{b})$$

Here $f$ is an activation function applied entry-by-entry to the result. A popular choice is ReLU, which keeps positive values and zeroes out negatives — cheap to compute and surprisingly good at helping signals survive many layers without shrinking away.

Chain several such layers together and you get a deep network: $\mathbf{a}^{(1)} \to \mathbf{a}^{(2)} \to \cdots \to \hat{y}$. The golden rule: depth lets a network compose simple transformations into complex ones, the same way $(f \circ g \circ h)(x)$ can describe curves no single function handles cleanly.

Practice problem. A one-layer network has weight matrix $W = \begin{bmatrix} 2 & -1 \end{bmatrix}$ and bias $b = 1$. Given input $\mathbf{x} = \begin{bmatrix} 3 \\ 4 \end{bmatrix}$, compute $z = W\mathbf{x} + b$. Then apply ReLU — defined as $\max(0, z)$ — to find $\text{ReLU}(z)$.
