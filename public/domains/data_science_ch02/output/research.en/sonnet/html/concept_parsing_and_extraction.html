Parsing And Extraction

Definition. Parsing is the process of analysing a sequence of symbols according to a formal grammar and constructing a structured representation — typically a tree — that encodes the syntactic relationships among those symbols. Extraction is the subsequent operation of selecting and returning specific sub-structures or values from that tree. Formally, let $\Sigma$ be an alphabet and $G = (V, \Sigma, R, S)$ a context-free grammar with variables $V$, production rules $R$, and start symbol $S$. A parse tree for a string $w \in \Sigma^*$ is a rooted ordered tree $T$ in which each internal node is labelled by a variable, each leaf is labelled by a terminal symbol, and the children of every internal node correspond to the right-hand side of some rule $r \in R$ applied at that node. Extraction then defines a function $\phi : T \to D$ mapping selected nodes or paths in $T$ to a target domain $D$.

Worked Example. Consider the arithmetic expression $e = \texttt{"3 + 4 * 2"}$ and the grammar

$$S \to S + T \mid T, \quad T \to T * F \mid F, \quad F \to \textbf{num}$$

A recursive-descent parser builds the tree $S(S(T(F(3))),\,+,\,T(T(F(4)),\,,\,F(2)))$. Operator precedence is encoded structurally: the multiplication node sits deeper in the tree than the addition node, so any left-to-right evaluator naturally computes $4 \times 2$ before adding $3$. Extraction of the root operator yields $+$; extraction of the right sub-tree's operator yields $$.

Key Theorem (Unambiguity and Unique Extraction). If grammar $G$ is unambiguous — meaning every $w \in L(G)$ has exactly one parse tree — then for any extraction function $\phi$ defined on tree structure, the value $\phi(T)$ is uniquely determined by $w$. Ambiguous grammars violate this guarantee: a string may admit two trees differing in operator precedence, so extraction becomes ill-defined without an explicit disambiguation rule.

Lab Cell.

from sympy.parsing.sympy_parser import parse_expr
from sympy import symbols

x, y = symbols('x y')

expr_str = "3 + 4 * x**2 - y"
expr = parse_expr(expr_str)

print("Parsed expression :", expr)
print("Free symbols      :", expr.free_symbols)
print("Degree in x       :", expr.as_poly(x).degree())

Running this cell demonstrates that SymPy's parser applies standard precedence rules, constructing an unambiguous internal tree from which .free_symbols and .degree() perform targeted extraction without re-parsing the string.
