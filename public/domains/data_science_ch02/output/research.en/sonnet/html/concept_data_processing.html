Data Processing

Definition. Data processing is the systematic transformation of raw observations into a structured, analytically tractable form. Formally, let $\mathcal{D} = \{x_i\}_{i=1}^{n}$ be a finite sample drawn from a population with distribution $P$. A processing pipeline is a composition of functions

$$ \phi = \phi_k \circ \phi_{k-1} \circ \cdots \circ \phi_1 : \mathcal{X}_{\text{raw}} \longrightarrow \mathcal{X}_{\text{clean}}, $$

where each $\phi_j$ addresses a specific data quality concern: missing-value imputation, outlier removal, type coercion, or feature scaling. The goal is to produce a representation $\tilde{\mathcal{D}} = \phi(\mathcal{D})$ on which subsequent statistical or machine-learning methods yield valid and reproducible results.

Worked Example. Consider the sample $\mathcal{D} = \{2,\, 7,\, \text{NaN},\, 105,\, 4\}$ representing daily energy consumption (kWh). Three transformations are applied in sequence.

  • Imputation ($\phi_1$): Replace the missing value with the sample median. The sorted non-missing values are $\{2, 4, 7, 105\}$, giving median $\tilde{m} = (4+7)/2 = 5.5$. The result is $\mathcal{D}^{(1)} = \{2, 7, 5.5, 105, 4\}$.
  • Outlier removal ($\phi_2$): Retain only observations within $\mu \pm 3\sigma$. Here $\mu = 24.7$ and $\sigma \approx 41.8$, so the interval is $(-100.7,\; 150.1)$. All values pass, but in practice the value $105$ warrants domain scrutiny.
  • Min–max scaling ($\phi_3$): Map each observation to $[0,1]$ via
    • $$ x' = \frac{x - x_{\min}}{x_{\max} - x_{\min}}. $$

    With $x_{\min} = 2$ and $x_{\max} = 105$ the observation $7$ maps to $x' = 5/103 \approx 0.049$.

    Key Theorem (Consistency of Sample Statistics Under Imputation). Let $\hat{\mu}_n$ denote the sample mean computed after mean imputation of $m$ missing values among $n$ total slots. Then $\hat{\mu}_n$ is identical to the complete-case mean $\bar{x}_{n-m}$, but its variance is underestimated by a factor of $(n-m)/n$. Consequently, imputation inflates the apparent precision of the estimate; variance-corrected inference requires multiple imputation or likelihood-based methods.

    Lab Cell.

    import sympy as sp
import statistics

data_raw = [2, 7, None, 105, 4]

# Impute with median of non-missing values
non_missing = [x for x in data_raw if x is not None]
med = statistics.median(non_missing)
data_imputed = [x if x is not None else med for x in data_raw]

# Min-max scaling
x_min, x_max = sp.Rational(min(data_imputed)), sp.Rational(max(data_imputed))
data_scaled = [sp.Rational(x) - x_min) / (x_max - x_min) for x in data_imputed]

print("Imputed:", data_imputed)
print("Scaled: ", [float(v) for v in data_scaled])

    Running this cell confirms $\phi_3(\phi_1(\mathcal{D})) = [0,\; 0.049,\; 0.034,\; 1.0,\; 0.019]$, providing a clean, bounded representation ready for downstream analysis.
