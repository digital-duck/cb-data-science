String Manipulation

Definition. A string over an alphabet $\Sigma$ is a finite sequence of symbols drawn from $\Sigma$. Formally, a string $s$ of length $n$ is a function $s : \{0, 1, \ldots, n-1\} \to \Sigma$, and we write $|s| = n$. The set of all finite strings over $\Sigma$, including the empty string $\varepsilon$, is denoted $\Sigma^$. String manipulation encompasses any operation that transforms one or more elements of $\Sigma^$ into another: concatenation, slicing, substitution, splitting, and pattern matching, among others.

The fundamental binary operation is concatenation. Given strings $s, t \in \Sigma^$, their concatenation $s \cdot t$ (often written $st$) is the string of length $|s| + |t|$ obtained by appending $t$ to $s$. Concatenation is associative, $(r \cdot s) \cdot t = r \cdot (s \cdot t)$, and $\varepsilon$ serves as the identity element, making $(\Sigma^, \cdot, \varepsilon)$ a monoid.

Worked Example. Let $\Sigma = \{a, b, \ldots, z\}$ and consider $s = \texttt{"linear"}$, $t = \texttt{"algebra"}$. Concatenation gives $st = \texttt{"linearalgebra"}$ with $|st| = 13 = 6 + 7$. The reverse of $s$, denoted $s^R$, is $\texttt{"raeniL"}$ (case-insensitive here). A string satisfying $s = s^R$ is called a palindrome; the string $\texttt{"racecar"}$ is a canonical example. Slicing extracts a substring: in zero-based indexing, $s[2:5] = \texttt{"nea"}$, corresponding to characters at positions $2, 3, 4$.

Key Theorem (String Equality via Hashing). The Rabin–Karp rolling-hash scheme assigns to each string $s = s_0 s_1 \cdots s_{n-1}$ the hash value

$$H(s) = \sum_{i=0}^{n-1} s_i \, p^{\,i} \pmod{q},$$

where $p$ is a prime base and $q$ a large prime modulus. With high probability, $H(s) = H(t)$ if and only if $s = t$, enabling substring search in expected $O(n + m)$ time for a text of length $n$ and a pattern of length $m$.

from sympy import symbols, Function

text    = "the cat sat on the mat"
pattern = "at"

# find all starting indices of pattern in text
indices = [i for i in range(len(text)) if text[i:i+len(pattern)] == pattern]
print("Occurrences of", repr(pattern), "at indices:", indices)

# demonstrate rolling hash concept
p, q = 31, 10**9 + 9
def rhash(s):
    return sum(ord(c) * p**i for i, c in enumerate(s)) % q

print("Hash match:", rhash("at") == rhash("at"), "| Collision test:", rhash("at") == rhash("ta"))
