Data Chunking

Definition. Given a sequence of $n$ data elements $S = (s_1, s_2, \ldots, s_n)$ and a chunk size $k \in \mathbb{Z}^+$, data chunking is the partition of $S$ into $\lceil n/k \rceil$ contiguous subsequences (chunks) $C_1, C_2, \ldots, C_{\lceil n/k \rceil}$, where

$$C_i = \bigl(s_{(i-1)k+1},\, s_{(i-1)k+2},\, \ldots,\, s_{\min(ik,\, n)}\bigr), \quad i = 1, 2, \ldots, \lceil n/k \rceil.$$

The chunks are pairwise disjoint and their union recovers $S$ exactly:

$$\bigsqcup_{i=1}^{\lceil n/k \rceil} C_i = S.$$

Chunking transforms an arbitrarily large, monolithic sequence into bounded units amenable to parallel processing, memory-constrained computation, or windowed analysis.

Worked Example. Let $S = (2, 5, 1, 8, 4, 7, 3, 6)$ with $n = 8$ and chunk size $k = 3$. Then $\lceil 8/3 \rceil = 3$ chunks are formed:

$$C_1 = (2, 5, 1), \quad C_2 = (8, 4, 7), \quad C_3 = (3, 6).$$

Note that $|C_3| = 2 < k$; the final chunk holds the remainder $n \bmod k = 2$ elements. The per-chunk sum vector is $(8, 19, 9)$, and the global sum $\sum_{s \in S} s = 36$ equals $8 + 19 + 9$, illustrating that additive aggregates distribute perfectly across chunks.

Key Theorem (Additivity of Chunk Aggregates). Let $f : 2^S \to \mathbb{R}$ be a function expressible as a commutative, associative binary operation $\oplus$ applied to element-wise values $\phi(s)$. Then

$$f(S) = \bigoplus_{i=1}^{\lceil n/k \rceil} f(C_i).$$

Proof sketch. By associativity and commutativity of $\oplus$, the order of application is immaterial. Partitioning $S$ into chunks and reducing each chunk independently before combining yields the same element-wise accumulation as processing $S$ in a single pass. $\square$

This theorem underpins map-reduce architectures: functions such as sum, product, maximum, and count all satisfy the additivity condition.

Lab Cell.

from sympy import symbols, summation, floor, ceiling

# Symbolic chunk count
n, k = symbols('n k', positive=True, integer=True)

# Number of chunks
num_chunks = ceiling(n / k)

# Verify for n=8, k=3
print(num_chunks.subs({n: 8, k: 3}))   # → 3

# Concrete chunking utility
def chunk(seq, k):
    return [seq[i*k:(i+1)*k] for i in range(-(-len(seq) // k))]

S = [2, 5, 1, 8, 4, 7, 3, 6]
chunks = chunk(S, 3)
print(chunks)            # [[2,5,1],[8,4,7],[3,6]]
print(sum(sum(c) for c in chunks) == sum(S))  # True
