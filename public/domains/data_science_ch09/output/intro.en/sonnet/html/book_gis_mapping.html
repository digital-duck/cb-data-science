Concept Book: Gis Mapping

Data Science Ch09 · Generated by SPL

Payoff

Imagine you are standing in a city you have never visited, holding a paper map. The map is not the city — it is a translation: every street corner, every park, every elevation change has been folded into a flat sheet of symbols. What makes the map useful is not that it copies reality, but that it preserves the relationships that matter. Two places that are neighbours on the ground stay neighbours on the page.

GIS mapping is that same idea, powered by mathematics and made interactive. At its heart, it asks one question: how do we assign coordinates to things in the world so that the structure we care about — distance, adjacency, flow — survives the translation? The answer turns out to require surprisingly little: a coordinate reference system, a projection that trades some distortion for a flat canvas, and a rule for layering different kinds of information on top of each other.

Formally, a projection is a function $f: \mathbb{S}^2 \to \mathbb{R}^2$ from the sphere to the plane. No such function is perfect — a theorem guarantees it cannot preserve both shape and area simultaneously — so every map is a deliberate choice about which distortion is acceptable for the task at hand.

That choice is where the concept earns its keep. Once you can locate anything in a shared coordinate space, you can combine datasets that were never designed to talk to each other: census records, satellite imagery, flood-risk models, hospital locations. The map becomes a reasoning surface.

Pick one thread and pull it. How would you use a GIS layer to decide where to site a new school so that every child lives within walking distance? Work out which datasets you would need, which projection you would choose, and what a "good" answer even looks like.
