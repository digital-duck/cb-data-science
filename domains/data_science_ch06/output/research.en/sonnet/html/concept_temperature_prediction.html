Temperature Prediction

Definition. Temperature prediction is the problem of estimating the value of a continuous scalar field $T(\mathbf{x}, t) : \mathbb{R}^d \times \mathbb{R} \to \mathbb{R}$ at a future time $t + \Delta t$, given observations $\{(\mathbf{x}_i, t_i, T_i)\}_{i=1}^n$. In the simplest one-dimensional, single-step setting, we seek a function $\hat{T}$ such that

$$\hat{T}(t + \Delta t) \approx T(t + \Delta t),$$

where the approximation is measured by mean squared error $\mathrm{MSE} = \frac{1}{n}\sum_{i=1}^n (\hat{T}_i - T_i)^2$.

Worked Example. Suppose daily high temperatures (°C) at a fixed station over four consecutive days are $T_1 = 18,\ T_2 = 20,\ T_3 = 19,\ T_4 = 21$. A first-order linear trend model posits

$$T(t) = \alpha + \beta t,$$

with $t \in \{1, 2, 3, 4\}$. The ordinary least-squares estimates are

$$\hat{\beta} = \frac{\sum_{i=1}^4 (t_i - \bar{t})(T_i - \bar{T})}{\sum_{i=1}^4 (t_i - \bar{t})^2}, \qquad \hat{\alpha} = \bar{T} - \hat{\beta}\,\bar{t}.$$

Here $\bar{t} = 2.5$ and $\bar{T} = 19.5$. Computing: $\hat{\beta} = \frac{(-1.5)(-1.5)+(-0.5)(0.5)+(0.5)(-0.5)+(1.5)(1.5)}{5} = \frac{4.5+(-0.25)+(-0.25)+2.25}{5} = \frac{5}{5} = 1$... let us recalculate carefully: numerator $= (-1.5)(-1.5) + (-0.5)(0.5) + (0.5)(-0.5) + (1.5)(1.5) = 2.25 - 0.25 - 0.25 + 2.25 = 4$, denominator $= 2.25 + 0.25 + 0.25 + 2.25 = 5$. Thus $\hat{\beta} = 0.8$ and $\hat{\alpha} = 19.5 - 0.8(2.5) = 17.5$. The prediction for day 5 is $\hat{T}(5) = 17.5 + 0.8 \times 5 = 21.5\,°\mathrm{C}$.

Key Theorem (Gauss–Markov). Under the linear model $\mathbf{T} = \mathbf{X}\boldsymbol{\beta} + \boldsymbol{\varepsilon}$ with $\mathbb{E}[\boldsymbol{\varepsilon}] = \mathbf{0}$ and $\mathrm{Var}(\boldsymbol{\varepsilon}) = \sigma^2 \mathbf{I}$, the OLS estimator $\hat{\boldsymbol{\beta}} = (\mathbf{X}^\top \mathbf{X})^{-1}\mathbf{X}^\top \mathbf{T}$ is the Best Linear Unbiased Estimator (BLUE): among all linear unbiased estimators, it minimises variance component-wise.

Lab Cell.

import sympy as sp

t = sp.symbols('t')
data = [(1, 18), (2, 20), (3, 19), (4, 21)]
n = len(data)
t_mean = sp.Rational(sum(d[0] for d in data), n)
T_mean = sp.Rational(sum(d[1] for d in data), n)

beta = sum((d[0]-t_mean)*(d[1]-T_mean) for d in data) / \
       sum((d[0]-t_mean)**2 for d in data)
alpha = T_mean - beta * t_mean

T_hat = alpha + beta * t
print("Model:", T_hat, "  Day-5 prediction:", T_hat.subs(t, 5))
