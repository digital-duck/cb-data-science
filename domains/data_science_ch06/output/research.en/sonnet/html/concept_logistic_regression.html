Logistic Regression

Definition. Logistic regression is a supervised classification model that estimates the probability that an observation $\mathbf{x} \in \mathbb{R}^n$ belongs to class $y = 1$. Rather than modeling $y$ directly, it applies the logistic (sigmoid) function

$$\sigma(z) = \frac{1}{1 + e^{-z}}, \qquad z \in \mathbb{R},$$

to a linear combination of the features. The model is therefore

$$P(y = 1 \mid \mathbf{x}; \boldsymbol{\theta}) = \sigma(\boldsymbol{\theta}^\top \mathbf{x}) = \frac{1}{1 + e^{-\boldsymbol{\theta}^\top \mathbf{x}}},$$

where $\boldsymbol{\theta} \in \mathbb{R}^n$ is the parameter vector learned from data. The output lies in $(0, 1)$, making it a valid probability. The decision boundary is the hyperplane $\boldsymbol{\theta}^\top \mathbf{x} = 0$, with $\hat{y} = 1$ when $\sigma(\boldsymbol{\theta}^\top \mathbf{x}) \geq 0.5$.

Worked Example. Suppose a student's exam score $x \in [0, 100]$ predicts pass ($y=1$) or fail ($y=0$). Suppose we fit $\theta_0 = -6,\, \theta_1 = 0.1$, so the log-odds are $z = -6 + 0.1x$. For a score of $x = 70$:

$$z = -6 + 0.1(70) = 1, \qquad \sigma(1) = \frac{1}{1+e^{-1}} \approx 0.731.$$

The model estimates a 73.1% probability of passing. The decision boundary occurs at $z = 0$, i.e., $x = 60$.

Key Theorem (Maximum-Likelihood Estimation). Parameters $\boldsymbol{\theta}$ are chosen to maximise the log-likelihood over a training set $\{(\mathbf{x}^{(i)}, y^{(i)})\}_{i=1}^m$:

$$\ell(\boldsymbol{\theta}) = \sum_{i=1}^{m} \left[ y^{(i)} \log \hat{p}^{(i)} + (1 - y^{(i)}) \log(1 - \hat{p}^{(i)}) \right],$$

where $\hat{p}^{(i)} = \sigma(\boldsymbol{\theta}^\top \mathbf{x}^{(i)})$. Because $\ell$ is concave in $\boldsymbol{\theta}$, gradient ascent (equivalently, minimising the binary cross-entropy $-\ell$) converges to the unique global maximum.

Lab Cell.

from sympy import symbols, Rational, exp, simplify

theta0, theta1, x = symbols('theta_0 theta_1 x')
z = theta0 + theta1 * x
sigma = 1 / (1 + exp(-z))

# Evaluate at theta0=-6, theta1=0.1, x=70
prob = sigma.subs({theta0: -6, theta1: Rational(1, 10), x: 70})
print("P(pass | x=70) =", simplify(prob).evalf(4))

Running this cell confirms $P \approx 0.7311$, matching the worked example.
