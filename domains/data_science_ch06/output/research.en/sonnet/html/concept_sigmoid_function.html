Sigmoid Function

Definition. The sigmoid function (also called the logistic function) is the map $\sigma : \mathbb{R} \to (0, 1)$ defined by

$$\sigma(x) = \frac{1}{1 + e^{-x}}.$$

It belongs to the broader family of sigmoidal (S-shaped) curves, but in the context of machine learning and mathematical biology, "the sigmoid" refers specifically to this logistic form. Key structural properties follow immediately from the definition: $\sigma(0) = \tfrac{1}{2}$, $\lim_{x \to +\infty} \sigma(x) = 1$, and $\lim_{x \to -\infty} \sigma(x) = 0$. The function is strictly increasing, smooth ($C^\infty$), and bounded, making it a natural tool for compressing real-valued inputs into probability-like outputs.

Worked Example. Suppose a binary classifier assigns a raw score $z = 2.5$ to an input. To interpret this score as a probability, apply $\sigma$:

$$\sigma(2.5) = \frac{1}{1 + e^{-2.5}} = \frac{1}{1 + 0.0821} \approx 0.924.$$

The classifier therefore estimates an $92.4\%$ probability that the input belongs to the positive class. Conversely, for $z = -1.0$:

$$\sigma(-1.0) = \frac{1}{1 + e^{1}} \approx \frac{1}{3.718} \approx 0.269.$$

Observe the symmetry $\sigma(-x) = 1 - \sigma(x)$, which reflects the graph's rotational symmetry about $(0, \tfrac{1}{2})$.

Key Theorem (Self-derivative property). The sigmoid satisfies

$$\sigma'(x) = \sigma(x)\bigl(1 - \sigma(x)\bigr).$$

Proof sketch. Write $\sigma(x) = (1 + e^{-x})^{-1}$ and differentiate via the chain rule:

$$\sigma'(x) = \frac{e^{-x}}{(1+e^{-x})^2} = \frac{1}{1+e^{-x}} \cdot \frac{e^{-x}}{1+e^{-x}} = \sigma(x)\bigl(1-\sigma(x)\bigr). \qquad \square$$

This identity is essential in backpropagation: the gradient through a sigmoid neuron requires no transcendental evaluation beyond the forward-pass output already stored in memory.

Lab Cell.

import sympy as sp

x = sp.Symbol('x', real=True)
sigma = 1 / (1 + sp.exp(-x))

deriv = sp.diff(sigma, x)
simplified = sp.simplify(deriv - sigma * (1 - sigma))
print("Derivative equals σ(1−σ):", simplified == 0)  # True

sp.plot(sigma, (x, -6, 6), title='Sigmoid Function', ylabel='σ(x)')

Running this cell confirms the self-derivative identity symbolically and renders the characteristic S-curve, saturating toward $0$ and $1$ in the tails.
