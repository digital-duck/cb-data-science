Labeled Unlabeled Data

Imagine you just got a big box of mystery crayons — no labels, no wrappers. You have to guess every color by trying it on paper first. That takes forever! Now imagine a friend already wrote "red," "blue," and "yellow" on most of them. Suddenly, sorting is easy.

Machine learning faces exactly this problem. A labeled example is like a crayon with a name on it: a photo of a cat with the word "cat" written underneath. The computer learns from those names. An unlabeled example is the mystery crayon — just a photo, no hint.

Here is the tricky part: labeling costs time and money (a human has to write each answer). But unlabeled data is everywhere and free. So scientists invented clever tricks that let a computer learn from both — using the labeled examples as guides and the unlabeled ones to notice patterns on its own.

Think of it as: labeled data teaches what things are called, unlabeled data teaches how things are shaped.

Now you try: Look at ten objects around you. Pick three and write their names. Could you still sort all ten into groups using only those three labels as clues?
