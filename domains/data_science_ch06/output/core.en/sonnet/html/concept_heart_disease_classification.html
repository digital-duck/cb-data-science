Heart Disease Classification

You already have the intuition: a doctor looks at a patient's age, blood pressure, and cholesterol, then decides whether that person is at risk for heart disease. Classification is exactly that decision-making process — turned into math.

Exploring the structure. In a classification problem, each patient is described by a set of features, often written as a vector $\mathbf{x} = (x_1, x_2, \ldots, x_n)$. For heart disease, typical features include age ($x_1$), resting blood pressure in mmHg ($x_2$), and serum cholesterol in mg/dL ($x_3$). The model learns a function $f(\mathbf{x})$ that maps these features to a label $y$, where we might define:

$$y = \begin{cases} 1 & \text{heart disease present} \\ 0 & \text{no heart disease} \end{cases}$$

A simple starting model is a threshold rule: pick one feature and draw a boundary. For example, if resting blood pressure alone is used, the rule might be:

$$\hat{y} = \begin{cases} 1 & \text{if } x_2 > 130 \\ 0 & \text{otherwise} \end{cases}$$

Of course, one feature is rarely enough — real classifiers combine many features and learn which threshold for each feature matters most.

The key pattern. Classification always has two ingredients: features that describe the input, and labels that describe the output. Training means finding the boundary $f(\mathbf{x})$ that best separates the classes using past examples.
