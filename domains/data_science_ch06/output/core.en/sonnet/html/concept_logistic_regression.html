Logistic Regression

You already know that linear regression draws a line to predict a number — like estimating someone's height from their age. But what if you need to predict a category instead, like "pass or fail," "spam or not spam," or "cat or dog"? That's where logistic regression comes in.

The key insight is that we don't predict the label directly. Instead, we predict the probability that something belongs to one class. A probability must stay between 0 and 1, so we can't just use a raw line — it could shoot off to infinity. We fix this by wrapping our linear formula inside a special function called the sigmoid:

$$\hat{p} = \sigma(z) = \frac{1}{1 + e^{-z}}, \quad z = w_1 x_1 + w_2 x_2 + \cdots + b$$

No matter how large or small $z$ gets, $\sigma(z)$ always lands between 0 and 1. It creates that distinctive S-shaped curve: nearly 0 on the left, rising through 0.5 in the middle, nearly 1 on the right.

Once you have $\hat{p}$, you apply a simple decision rule:

$$\text{predict Class 1 if } \hat{p} \geq 0.5, \text{ otherwise predict Class 0}$$

The weights $w_1, w_2, \ldots$ and bias $b$ are learned from data, just like in linear regression, but using a different cost function called log loss (also called cross-entropy).

Practice Problem: A logistic regression model gives $z = 2.0$ for a student's exam score. Compute $\hat{p} = \sigma(2.0)$ using the sigmoid formula (use $e \approx 2.718$). Would the model predict "pass" (Class 1) or "fail" (Class 0)?
