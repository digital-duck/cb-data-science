Supervised Learning

You've probably already seen supervised learning in action: a spam filter that learns from thousands of labeled emails, or a photo app that recognizes faces. The key word is labeled — someone already told the system the right answer for each example. That's the "supervision."

The structure underneath. Formally, supervised learning works with a dataset of paired examples:

$$\{(x_1, y_1),\ (x_2, y_2),\ \ldots,\ (x_n, y_n)\}$$

Each $x_i$ is an input (a photo, a sentence, a set of measurements) and each $y_i$ is the corresponding label (the correct answer a human provided). The algorithm searches for a function $f$ such that $f(x) \approx y$ — meaning: given a new, unseen input, it predicts the right label.

There are two main flavors depending on what $y$ looks like:

  • Classification — $y$ is a category (spam / not spam, cat / dog). The algorithm draws decision boundaries between groups.
  • Regression — $y$ is a number (a house price, a temperature). The algorithm fits a curve through the data.

    • The core pattern. In both cases, the learning algorithm measures its mistakes using a loss function $L(\hat{y}, y)$ — a number that grows larger the further the prediction $\hat{y}$ is from the true label $y$. Training means adjusting $f$ to make $L$ as small as possible.
