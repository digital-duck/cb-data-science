Facial Recognition

Definition. Facial recognition is the automated identification of individuals from digital images or video frames by extracting and comparing geometric or statistical features of the face. Formally, let $\mathcal{F}$ denote the space of facial images, each represented as a vector $\mathbf{x} \in \mathbb{R}^d$ where $d = H \times W$ (height times width in pixels). A facial recognition system learns a mapping $f: \mathbb{R}^d \to \mathbb{R}^k$ that projects each image into a low-dimensional embedding space $\mathbb{R}^k$ ($k \ll d$), such that images of the same individual are mapped to nearby points and images of different individuals are mapped to distant points. Recognition then reduces to nearest-neighbor search: given a query embedding $\mathbf{z}_q = f(\mathbf{x}_q)$, assign identity $i^$ where $i^ = \arg\min_i \|\mathbf{z}_q - \mathbf{z}_i\|_2$.

Worked Example. Suppose we reduce $d = 100 \times 100 = 10{,}000$ pixel images to $k = 3$ principal components using PCA. Compute the mean face $\bar{\mathbf{x}} = \frac{1}{n}\sum_{i=1}^n \mathbf{x}_i$ and the covariance matrix $\Sigma = \frac{1}{n}\sum_{i=1}^n (\mathbf{x}_i - \bar{\mathbf{x}})(\mathbf{x}_i - \bar{\mathbf{x}})^\top$. The top-$k$ eigenvectors $\mathbf{u}_1, \mathbf{u}_2, \mathbf{u}_3$ of $\Sigma$ form the eigenface basis. A new image $\mathbf{x}$ is embedded as $\mathbf{z} = U^\top(\mathbf{x} - \bar{\mathbf{x}})$ where $U = [\mathbf{u}_1 \mid \mathbf{u}_2 \mid \mathbf{u}_3]$. Identity is determined by finding the gallery embedding $\mathbf{z}_i$ minimizing $\|\mathbf{z} - \mathbf{z}_i\|_2$.

Key Theorem (Eckart–Young–Mirsky). Among all rank-$k$ approximations $\hat{\Sigma}$ of a symmetric positive semidefinite matrix $\Sigma$, the truncated eigendecomposition $\hat{\Sigma}_k = \sum_{j=1}^k \lambda_j \mathbf{u}_j \mathbf{u}_j^\top$ minimizes $\|\Sigma - \hat{\Sigma}\|_F$, where $\|\cdot\|_F$ denotes the Frobenius norm. This guarantees that PCA retains the maximum variance in $k$ dimensions, making it the optimal linear dimensionality reduction for recognition tasks.

import numpy as np
from sympy import Matrix, symbols, sqrt, Rational

# Toy 4-pixel face gallery (each row = one flattened image)
X = Matrix([
    [1, 2, 3, 4],
    [2, 3, 4, 5],
    [9, 8, 7, 6],
    [8, 7, 6, 5],
])

mean_face = X.T * Matrix([Rational(1,4)] * 4)
X_centered = X - Matrix([[mean_face.T]] * 4)

# Covariance (symbolic, small example)
C = X_centered.T * X_centered * Rational(1, 4)
print("Covariance matrix:")
print(C)

# Eigenvalues reveal dominant variance directions
eigenvals = C.eigenvals()
print("Eigenvalues:", eigenvals)
