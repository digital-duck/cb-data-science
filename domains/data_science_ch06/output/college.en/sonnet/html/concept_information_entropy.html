Information Entropy

Definition. Let $X$ be a discrete random variable taking values in a finite alphabet $\mathcal{X} = \{x_1, x_2, \ldots, x_n\}$ with probability mass function $p(x_i) = P(X = x_i)$. The Shannon entropy of $X$ is

$$H(X) = -\sum_{i=1}^{n} p(x_i)\log_2 p(x_i),$$

where the convention $0 \log_2 0 = 0$ handles zero-probability outcomes. The unit is the bit. Entropy measures the average uncertainty inherent in $X$: how many binary questions, on average, are needed to determine an outcome drawn from this distribution.

Worked Example. Consider a fair coin: $p(\text{H}) = p(\text{T}) = \tfrac{1}{2}$. Then

$$H(X) = -\tfrac{1}{2}\log_2\tfrac{1}{2} - \tfrac{1}{2}\log_2\tfrac{1}{2} = -2 \cdot \tfrac{1}{2}\cdot(-1) = 1 \text{ bit}.$$

Now consider a biased coin with $p(\text{H}) = \tfrac{3}{4}$, $p(\text{T}) = \tfrac{1}{4}$:

$$H(X) = -\tfrac{3}{4}\log_2\tfrac{3}{4} - \tfrac{1}{4}\log_2\tfrac{1}{4} \approx 0.311 + 0.500 = 0.811 \text{ bits}.$$

The biased coin carries less uncertainty: knowing it is likely to land heads makes the outcome easier to anticipate.

Key Theorem (Maximum Entropy). Among all probability distributions over an alphabet of size $n$, the uniform distribution $p(x_i) = 1/n$ uniquely maximises entropy, achieving

$$H_{\max} = \log_2 n \text{ bits}.$$

Proof sketch. By the concavity of $-p\log p$ and Jensen's inequality, $H(X) \leq \log_2 n$, with equality if and only if all $p(x_i)$ are equal. $\square$

Entropy is also bounded below by $0$ bits, achieved when one outcome has probability $1$ — a deterministic variable contains no information.

Lab Cell.

from sympy import Rational, log, N

probs = [Rational(1, 4), Rational(3, 4)]          # biased coin
H = -sum(p * log(p, 2) for p in probs if p > 0)
print("Entropy (exact):", H)
print("Entropy (decimal):", N(H, 6), "bits")

Running this cell returns $H = \tfrac{3}{4}\log_2\tfrac{4}{3} + \tfrac{1}{4}\log_2 4$ in symbolic form, confirming the numerical result of approximately $0.811$ bits. Modify probs to explore how concentration of probability mass reduces entropy toward zero.
