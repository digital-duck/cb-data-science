Data Mining

Definition. Data mining is the computational process of discovering structural patterns, statistical regularities, and predictive relationships in large datasets by combining methods from statistics, machine learning, and database theory. Formally, given a dataset $\mathcal{D} = \{x_1, x_2, \ldots, x_n\} \subset \mathbb{R}^d$, data mining seeks a model $f : \mathbb{R}^d \to \mathcal{Y}$ — or a set of rules $\mathcal{R}$ — that compactly describes the generating distribution $P(\mathbf{x})$ or a conditional distribution $P(y \mid \mathbf{x})$, where $y \in \mathcal{Y}$ is a target variable. The discipline is distinguished from pure statistics by its emphasis on scalability: algorithms must remain tractable as $n$ and $d$ grow to millions.

Worked Example. Consider a retail dataset of $n = 10{,}000$ transactions, each a binary vector $\mathbf{x} \in \{0,1\}^{500}$ indicating which of 500 products were purchased together. A foundational task is association rule mining: find pairs $(A, B)$ of item sets such that the support

$$\text{supp}(A \Rightarrow B) = \frac{|\{\mathbf{x} \in \mathcal{D} : A \cup B \subseteq \mathbf{x}\}|}{n}$$

exceeds a threshold $\sigma$, and the confidence

$$\text{conf}(A \Rightarrow B) = \frac{\text{supp}(A \cup B)}{\text{supp}(A)}$$

exceeds a threshold $\gamma$. Setting $\sigma = 0.02$ and $\gamma = 0.60$ might reveal, for example, that customers who purchase bread and butter also purchase jam with 63% confidence — an actionable insight for shelf placement.

Key Theorem (Apriori Anti-Monotonicity). If an item set $S$ has $\text{supp}(S) < \sigma$, then every superset $S' \supset S$ satisfies $\text{supp}(S') \leq \text{supp}(S) < \sigma$. This monotonicity of the support measure allows the Apriori algorithm to prune the exponential search space $2^{500}$ by discarding all extensions of low-support sets, reducing practical complexity to a manageable breadth-first traversal over frequent item sets only.

Lab Cell.

from sympy import Rational

transactions = [
    {"bread", "butter", "jam"},
    {"bread", "butter"},
    {"bread", "jam"},
    {"butter", "jam"},
    {"bread", "butter", "jam"},
]

n = len(transactions)
supp_AB  = sum(1 for t in transactions if {"bread","butter"} <= t) / n
supp_ABC = sum(1 for t in transactions if {"bread","butter","jam"} <= t) / n
conf     = Rational(int(supp_ABC * n), int(supp_AB * n))

print(f"supp(bread ∧ butter) = {supp_AB}")
print(f"conf(bread,butter ⇒ jam) = {conf}")

Running this cell yields $\text{conf} = \tfrac{2}{3} \approx 0.667$, confirming the rule at a 60% threshold.
