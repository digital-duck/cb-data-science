What Spam Filtering Achieves

A spam filter is, at its core, a binary classifier that partitions an incoming message space $\mathcal{X}$ into two disjoint classes: spam $(\mathcal{S})$ and ham $(\mathcal{H})$. Formally, we seek a decision function $f : \mathcal{X} \to \{0, 1\}$ that minimizes the expected misclassification cost

$$ R(f) = C_{01}\,P(f(x)=0 \mid x \in \mathcal{S})\,P(\mathcal{S}) + C_{10}\,P(f(x)=1 \mid x \in \mathcal{H})\,P(\mathcal{H}), $$

where $C_{01}$ penalizes a missed spam message and $C_{10}$ penalizes a falsely rejected legitimate message. The asymmetry $C_{01} \ll C_{10}$ encodes the real-world preference: it is far worse to silently discard a legitimate email than to let the occasional advertisement pass through. Every mathematical structure developed in this text — probability, feature extraction, Bayesian updating, and linear algebra — converges here into a single, deployable decision rule.

Spam filtering is the natural endpoint of this journey because it demands that every abstraction earn its keep. The bag-of-words model forces a precise account of how unstructured text becomes a vector in $\mathbb{R}^d$. Bayes' theorem supplies the update rule that converts word frequencies into posterior class probabilities. The log-odds ratio

$$ \log \frac{P(\mathcal{S} \mid x)}{P(\mathcal{H} \mid x)} = \log \frac{P(\mathcal{S})}{P(\mathcal{H})} + \sum_{i=1}^{d} n_i \log \frac{P(w_i \mid \mathcal{S})}{P(w_i \mid \mathcal{H})} $$

reduces classification to a dot product, linking probabilistic reasoning directly to the geometry of inner-product spaces.

Worked Example

Consider a vocabulary of three tokens: "winner", "unsubscribe", "meeting". A message containing "winner" twice and "unsubscribe" once, but not "meeting", is represented by the count vector $\mathbf{n} = (2, 1, 0)^\top$. After training on a labeled corpus, suppose the log-likelihood ratios for these tokens are $\boldsymbol{\lambda} = (1.8, 1.2, -0.9)^\top$ and the prior log-odds is $\log(P(\mathcal{S})/P(\mathcal{H})) = -1.0$. The decision statistic is

$$ \Delta = -1.0 + \mathbf{n}^\top \boldsymbol{\lambda} = -1.0 + (2)(1.8) + (1)(1.2) + (0)(-0.9) = -1.0 + 4.8 = 3.8 > 0, $$

so the message is classified as spam. The calculation occupies a single line of arithmetic, yet it synthesizes every foundational concept in this text.

Key Theorem — Optimality of the Naive Bayes Classifier

Theorem. Under the assumption that token occurrences are conditionally independent given the class label, the Naive Bayes classifier achieves the minimum Bayes risk $R(f^*)$ among all measurable classifiers.

Proof sketch. The Neyman–Pearson lemma guarantees that the optimal test for a two-class problem is the likelihood-ratio test with threshold $\tau = C_{10}/C_{01}$. Conditional independence reduces the class-conditional likelihood to a product over tokens, so the log-likelihood ratio collapses to the linear form $\Delta$ above. The classifier $f^(x) = \mathbf{1}[\Delta(x) > \log\tau]$ therefore attains $R(f^)$.

Lab Cell

from sympy import symbols, log, Rational, N

# token counts, log-likelihood ratios, prior log-odds
n = [2, 1, 0]
lam = [Rational(9,5), Rational(6,5), Rational(-9,10)]
prior = -1

delta = prior + sum(ni * li for ni, li in zip(n, lam))
print("Decision statistic:", N(delta))   # 3.8 → spam

Running this cell returns 3.8, confirming the worked example above and illustrating that the entire classification pipeline reduces to a handful of symbolic arithmetic operations.
