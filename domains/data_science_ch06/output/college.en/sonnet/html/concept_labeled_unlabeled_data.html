Labeled Unlabeled Data

Definition. A dataset $\mathcal{D}$ is a finite collection of input-output pairs drawn from some unknown joint distribution $p(x, y)$, where $x \in \mathcal{X}$ denotes an input (feature vector) and $y \in \mathcal{Y}$ denotes an output (label). We call an example $(x_i, y_i)$ labeled when the target value $y_i$ is observed, and unlabeled when only $x_i$ is available. Formally, partition $\mathcal{D}$ into

$$\mathcal{D}_L = \{(x_i, y_i)\}_{i=1}^{n_L}, \qquad \mathcal{D}_U = \{x_j\}_{j=1}^{n_U},$$

where typically $n_L \ll n_U$. The marginal distribution $p(x)$ governs both subsets, while $p(y \mid x)$ is the conditional we wish to learn. Acquiring labels is expensive (human annotation, laboratory assay, clinical diagnosis), so leveraging $\mathcal{D}_U$ to improve a model trained on $\mathcal{D}_L$ is the central problem of semi-supervised learning.

Worked Example. Suppose $\mathcal{X} = \mathbb{R}$ and $y \in \{0, 1\}$. We observe $n_L = 4$ labeled points: $(1, 0),\, (2, 0),\, (8, 1),\, (9, 1)$, and $n_U = 3$ unlabeled points: $4, 5, 6$. A purely supervised classifier trained on $\mathcal{D}_L$ might place the decision boundary at $x^ = 5$. The unlabeled cluster near $x = 5$ reveals that the input density $p(x)$ has a gap between $[2, 4]$ and $[6, 8]$; shifting $x^$ to the gap at $x = 5$ respects the cluster assumption: decision boundaries should lie in low-density regions of $p(x)$.

Key Theorem (Cluster Assumption, informal). If $p(x)$ is low near $x^$ and the true boundary coincides with a density valley, then the generalization error of a boundary placed at $x^$ is bounded by a term that decreases as $n_U \to \infty$, even when $n_L$ is fixed. Making this precise requires PAC-learning analysis beyond our current scope, but the intuition underpins methods such as label propagation and self-training.

Lab Cell.

from sympy import symbols, Piecewise, Rational, plot

x = symbols('x', real=True)

# Toy piecewise density illustrating a gap at x = 5
p = Piecewise(
    (Rational(1, 4), (x >= 1) & (x <= 4)),
    (Rational(1, 20), (x > 4) & (x < 6)),   # low-density gap
    (Rational(1, 4), (x >= 6) & (x <= 9)),
    (0, True)
)

plot(p, (x, 0, 10), title='Input density p(x) with gap',
     xlabel='x', ylabel='p(x)')

Running this cell renders the density valley near $x = 5$, making the geometric motivation for boundary placement visually immediate.
