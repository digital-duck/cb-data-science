Explainable Ai

You already know that AI models can make surprisingly good predictions — a model might correctly flag a suspicious bank transaction or recommend the perfect playlist. But here's a deeper question: why did it make that call? If the model can't tell you, that's a problem — especially in high-stakes situations like medical diagnoses or loan approvals.

Explainable AI (XAI) is the field that studies how to make model decisions transparent and interpretable.

One of the most widely used tools is feature importance. Suppose a model predicts whether a student will pass an exam using three inputs: hours studied ($x_1$), sleep hours ($x_2$), and attendance rate ($x_3$). After training, we can ask: how much did each feature contribute to the prediction? A technique called SHAP (SHapley Additive exPlanations) assigns each feature a score $\phi_i$ so that:

$$\hat{y} = \phi_0 + \phi_1 + \phi_2 + \phi_3$$

Here $\phi_0$ is the baseline (average prediction), and each $\phi_i$ shows how much feature $x_i$ pushed the prediction up or down. A large positive $\phi_1$ means studying a lot helped; a large negative $\phi_2$ means poor sleep hurt.

The key insight: a model is only trustworthy if you can audit its reasoning. A black-box model that happens to be right isn't necessarily safe — it might be right for the wrong reasons.

Practice Problem: A loan-approval model produces the SHAP values below for one applicant:

| Feature | $\phi_i$ | |---|---| | Credit score | $+0.30$ | | Debt-to-income ratio | $-0.45$ | | Employment years | $+0.10$ | | Baseline $\phi_0$ | $0.60$ |

What is the model's predicted approval score $\hat{y}$? Based on the signs, which single factor most hurt this applicant's chances?
