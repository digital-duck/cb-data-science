Definition. The GDPR/CCPA compliance framework is a set of legally mandated constraints on personal data processing that can be formalised as a tuple $\mathcal{C} = (S, \mathcal{P}, \mathcal{R}, \Phi)$, where $S$ is the universe of data subjects, $\mathcal{P}$ is the collection of processing purposes, $\mathcal{R}: S \times \mathcal{P} \to \{0,1\}$ is the consent relation, and $\Phi$ is a family of retention policies bounding how long each datum $d$ associated with subject $s$ may persist: $\phi_{s} \in \Phi$ satisfies $\text{age}(d) \leq \phi_{s}$ at all times. A data pipeline is lawful if and only if every operation $o(d, p)$ satisfies $\mathcal{R}(s(d), p) = 1$ and $\phi_{s(d)}$ is not violated.

This framework is the natural endpoint of the preceding chapters because privacy is not a single technique but the composition of every tool developed earlier — data minimisation, purpose limitation, cryptographic pseudonymisation, access-control lattices, and audit-log integrity — now brought into alignment with an enforceable external specification. GDPR and CCPA translate legal prose into the mathematical vocabulary you have been building all semester.

Worked example. A streaming service collects viewing histories $H = \{(u_i, v_j, t_k)\}$. The analytics pipeline computes watch-time aggregates $A_i = \sum_j w_{ij}$ for recommendation. Under GDPR Art. 5(1)(e), raw tuples must be deleted after 90 days: $\phi_{u_i} = 90\,\text{days}$. Pseudonymisation replaces $u_i$ with $h(u_i \,\|\, \text{salt})$ before any cross-system join, ensuring that a data breach exposes only the hash. Consent is recorded as $\mathcal{R}(u_i, \text{analytics}) = 1$ at registration; withdrawal sets this to $0$ and triggers automated purge of $A_i$ — a right-to-erasure event that propagates through every downstream cache via a deletion log.

Key theorem (Composition closure). If each sub-pipeline $\pi_k$ is individually lawful under $\mathcal{C}$, then their sequential composition $\pi_1 \circ \pi_2 \circ \cdots \circ \pi_n$ is lawful if and only if the output of $\pi_k$ introduces no new personal data outside the consented purposes of $\pi_{k+1}$. This follows directly from the transitivity of the consent relation and the monotone non-increase of retention windows through aggregation.

Lab cell.

from sympy import symbols, Piecewise, simplify

age, phi = symbols('age phi', nonneg=True)
is_lawful = Piecewise((1, age <= phi), (0, True))
# Verify erasure trigger at boundary
print(simplify(is_lawful.subs(age, phi)))   # 1  (boundary is lawful)
print(simplify(is_lawful.subs(age, phi+1))) # 0  (stale: must purge)
