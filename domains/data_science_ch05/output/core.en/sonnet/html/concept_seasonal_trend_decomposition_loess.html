Seasonal Trend Decomposition Loess

Definition. Given a univariate time series $\{Y_t\}_{t=1}^{N}$, Seasonal and Trend decomposition using Loess (STL) expresses each observation as the additive sum

$$Y_t = T_t + S_t + R_t,$$

where $T_t$ is a smooth trend component, $S_t$ is a periodic seasonal component with period $p$, and $R_t$ is a remainder (residual). Both the trend and seasonal components are estimated by fitting low-degree polynomials over sliding neighborhoods, where each neighboring observation receives a weight determined by its distance from the target point via the tricubic kernel:

$$w(u) = \begin{cases}(1 - |u|^3)^3, & |u| < 1,\\ 0, & \text{otherwise.}\end{cases}$$

The bandwidth parameters $n_s$ (seasonal smoothing window) and $n_t$ (trend smoothing window) control the flexibility of these fits; larger windows yield smoother, slower-varying estimates.

Worked Example. Consider monthly average temperatures recorded over five years ($N = 60$, $p = 12$). A pronounced annual cycle dominates the series. Running STL with $n_s = 13$ and $n_t = 23$ extracts: (1) a gently rising $T_t$ reflecting long-term warming, (2) a $S_t$ oscillating between $-8\,^{\circ}\text{C}$ and $+8\,^{\circ}\text{C}$ with period 12, and (3) small residuals $|R_t| < 1\,^{\circ}\text{C}$. Plotting all three panels confirms that most variance is explained by the seasonal component, with the trend capturing a secondary, slower signal.

Key Theorem (Robustness iterations). STL incorporates an optional outer loop of $n_o$ robustness passes. After each fit, observations whose residuals are large receive reduced influence before the estimation is repeated. Under mild regularity conditions on the data-generating process, this produces estimates $\hat{T}_t$ and $\hat{S}_t$ that are consistent and robust to up to $\lfloor N/2 \rfloor$ gross outliers.

Lab Cell.

import pandas as pd
from statsmodels.tsa.seasonal import STL
import matplotlib.pyplot as plt

series = pd.Series(data, index=pd.date_range("2020-01", periods=60, freq="ME"))
stl = STL(series, period=12, seasonal=13, trend=23, robust=True)
result = stl.fit()

result.plot()
plt.tight_layout()
plt.show()

print(result.trend[:5])
print(result.seasonal[:5])
print(result.resid[:5])

Vary seasonal between 7 and 25 and observe how the extracted $S_t$ changes; larger values force the seasonal component to evolve more slowly across years.
