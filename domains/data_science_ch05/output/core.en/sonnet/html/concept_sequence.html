Sequence

You already know the intuition: a sequence is a list of things in a specific order. But there's more structure here than a plain list. Unlike a set, where order doesn't matter, a sequence cares deeply about position — the third term is different from the first, even if they happen to have the same value.

Formal structure. A sequence is formally written as $(a_1, a_2, a_3, \ldots)$, where each $a_n$ is called the $n$-th term and $n$ is its index. The index usually starts at $1$ (sometimes $0$). What makes a sequence powerful is that each term can be defined by a rule — a formula that takes an index and produces a value.

Two common types:

  • Explicit formula: gives you $a_n$ directly. For example, $a_n = 2n + 1$ produces $3, 5, 7, 9, \ldots$
  • Recursive formula: defines each term using the one before it. For example, $a_1 = 1$ and $a_n = a_{n-1} + 3$ produces $1, 4, 7, 10, \ldots$

    • Pattern to remember. If consecutive terms differ by a constant amount $d$, you have an arithmetic sequence and the explicit formula is always:

    $$a_n = a_1 + (n - 1)d$$

    This single formula lets you jump directly to any term without listing everything before it.
