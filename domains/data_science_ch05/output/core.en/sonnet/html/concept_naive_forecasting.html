Naive Forecasting

Definition. Let $\{y_t\}_{t=1}^{T}$ be a univariate time series. The naive forecast for horizon $h \geq 1$ is defined as

$$\hat{y}_{T+h \mid T} = y_T,$$

that is, every future value is predicted to equal the most recently observed value. Equivalently, the naive method assumes that the best available information about the future is the present, with no trend, seasonality, or autocorrelation exploited beyond the last observation. Despite its simplicity, the naive forecast serves as the canonical baseline: any more sophisticated model must outperform it to justify its additional complexity.

A natural variant, the seasonal naive forecast, accommodates periodic data by setting

$$\hat{y}_{T+h \mid T} = y_{T+h-m},$$

where $m$ is the seasonal period (e.g., $m = 12$ for monthly data). Here the forecast for a given future month equals the value recorded in the same month of the previous cycle.

Worked Example. Suppose daily closing prices of a stock (in USD) for five consecutive days are

$$y_1 = 102,\quad y_2 = 105,\quad y_3 = 103,\quad y_4 = 107,\quad y_5 = 106.$$

The naive one-step-ahead forecast is $\hat{y}_6 = y_5 = 106$. The two-step-ahead forecast is equally $\hat{y}_7 = 106$. If the true value on day 6 turns out to be $y_6 = 109$, the forecast error is $e_6 = y_6 - \hat{y}_{6\mid 5} = 3$.

Key Theorem (Random Walk Optimality). If $\{y_t\}$ follows a random walk, i.e., $y_t = y_{t-1} + \varepsilon_t$ where $\varepsilon_t \overset{\text{iid}}{\sim}(0,\sigma^2)$, then the naive forecast minimizes the mean squared error among all linear unbiased predictors. Formally,

$$\mathbb{E}\!\left[(y_{T+h} - \hat{y}_{T+h\mid T})^2\right] = h\sigma^2,$$

which is the irreducible variance and cannot be reduced by any predictor that relies solely on the observed history $\{y_1,\ldots,y_T\}$.

Lab Cell.

import sympy as sp

# Symbolic naive forecast error variance for a random walk
h, sigma2 = sp.symbols('h sigma^2', positive=True)
mse = h * sigma2
print("MSE of naive forecast (random walk):", mse)

# Numerical example
prices = [102, 105, 103, 107, 106]
naive_forecast = prices[-1]          # 106
actual_day6    = 109
error          = actual_day6 - naive_forecast
print(f"Naive forecast: {naive_forecast}, Error: {error}")
