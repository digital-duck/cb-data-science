Stationary

Definition. Let $f : I \to \mathbb{R}$ be a differentiable function on an open interval $I$. A point $x_0 \in I$ is called a stationary point of $f$ if the derivative vanishes there:

$$f'(x_0) = 0.$$

Geometrically, the tangent line to the graph of $f$ at $(x_0, f(x_0))$ is horizontal. The value $f(x_0)$ is called a stationary value. Stationary points are the candidates for local extrema, but not every stationary point is an extremum — a point may be stationary and yet be neither a local maximum nor a local minimum.

Worked Example. Consider $f(x) = x^3 - 3x + 1$ on $\mathbb{R}$. Differentiating gives

$$f'(x) = 3x^2 - 3 = 3(x-1)(x+1).$$

Setting $f'(x) = 0$ yields stationary points at $x = -1$ and $x = 1$. The stationary values are $f(-1) = 3$ and $f(1) = -1$. To classify these points, compute the second derivative $f''(x) = 6x$. Since $f''(-1) = -6 < 0$, the point $x = -1$ is a local maximum; since $f''(1) = 6 > 0$, the point $x = 1$ is a local minimum.

Key Theorem (Second Derivative Test). Let $f$ be twice differentiable on $I$ and suppose $f'(x_0) = 0$. Then:

  • If $f''(x_0) > 0$, then $x_0$ is a strict local minimum.
  • If $f''(x_0) < 0$, then $x_0$ is a strict local maximum.
  • If $f''(x_0) = 0$, the test is inconclusive.

    • Proof sketch. When $f'(x_0) = 0$ and $f''(x_0) > 0$, the Taylor expansion $f(x_0 + h) \approx f(x_0) + \tfrac{1}{2}f''(x_0)h^2$ shows $f(x_0 + h) > f(x_0)$ for all sufficiently small $h \neq 0$, confirming a local minimum. The maximum case is symmetric. $\square$

    Note that case (3) requires further analysis; the function $g(x) = x^3$ satisfies $g'(0) = g''(0) = 0$ yet $x = 0$ is a point of inflection, not an extremum.

    Lab Cell.

    from sympy import symbols, diff, solve, latex

x = symbols('x')
f = x**3 - 3*x + 1

f_prime  = diff(f, x)
f_double = diff(f_prime, x)

stationary_pts = solve(f_prime, x)
for pt in stationary_pts:
    val        = f.subs(x, pt)
    curvature  = f_double.subs(x, pt)
    kind       = "min" if curvature > 0 else "max" if curvature < 0 else "inconclusive"
    print(f"x = {pt}: f = {val}, f'' = {curvature}  →  {kind}")
