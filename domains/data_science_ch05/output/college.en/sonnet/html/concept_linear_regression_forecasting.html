Linear Regression Forecasting

Definition. Given a sequence of observations $\{(x_i, y_i)\}_{i=1}^n$ where $x_i \in \mathbb{R}$ is an independent variable (often time) and $y_i \in \mathbb{R}$ is a response, simple linear regression posits the model

$$y_i = \beta_0 + \beta_1 x_i + \varepsilon_i, \quad \varepsilon_i \overset{\text{iid}}{\sim} \mathcal{N}(0, \sigma^2).$$

The ordinary least-squares (OLS) estimators $\hat{\beta}_0, \hat{\beta}_1$ minimise the residual sum of squares $\text{RSS} = \sum_{i=1}^n (y_i - \beta_0 - \beta_1 x_i)^2$. A forecast at a new point $x^$ is then $\hat{y}^ = \hat{\beta}_0 + \hat{\beta}_1 x^*$.

Worked Example. Suppose monthly sales (in thousands of units) over four months are recorded as $(1, 3),\,(2, 5),\,(3, 4),\,(4, 6)$. We compute

$$\bar{x} = 2.5, \quad \bar{y} = 4.5,$$ $$\hat{\beta}_1 = \frac{\sum_{i=1}^4 (x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^4 (x_i - \bar{x})^2} = \frac{(−1.5)(−1.5)+(−0.5)(0.5)+(0.5)(−0.5)+(1.5)(1.5)}{5} = \frac{4}{5} = 0.8,$$ $$\hat{\beta}_0 = \bar{y} - \hat{\beta}_1\bar{x} = 4.5 - 0.8(2.5) = 2.5.$$

The fitted line is $\hat{y} = 2.5 + 0.8x$. The forecast for month 5 is $\hat{y}^* = 2.5 + 0.8(5) = 6.5$ thousand units.

Key Theorem (Gauss–Markov). Under the assumptions that errors are zero-mean, homoscedastic, and uncorrelated, the OLS estimators $\hat{\beta}_0$ and $\hat{\beta}_1$ are the Best Linear Unbiased Estimators (BLUE): among all linear unbiased estimators, they achieve the minimum variance. Formally, for any linear unbiased estimator $\tilde{\beta}_1$, we have $\operatorname{Var}(\hat{\beta}_1) \leq \operatorname{Var}(\tilde{\beta}_1)$. The proof proceeds by writing $\tilde{\beta}_1 = \hat{\beta}_1 + \mathbf{c}^\top \mathbf{y}$ for some vector $\mathbf{c}$ orthogonal to the design matrix columns, then applying the unbiasedness constraint to show the extra variance term $\sigma^2 \|\mathbf{c}\|^2$ is non-negative.

from sympy import symbols, Rational, simplify

x, b0, b1 = symbols('x b0 b1')
data = [(1,3),(2,5),(3,4),(4,6)]
n = len(data)
x_bar = Rational(sum(p[0] for p in data), n)
y_bar = Rational(sum(p[1] for p in data), n)
b1_val = sum((p[0]-x_bar)*(p[1]-y_bar) for p in data) / \
         sum((p[0]-x_bar)**2 for p in data)
b0_val = y_bar - b1_val * x_bar
forecast = b0_val + b1_val * 5
print(f"β̂₀ = {b0_val}, β̂₁ = {b1_val}, forecast(x=5) = {forecast}")
