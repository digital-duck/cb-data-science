移动平均模型

直觉回顾：想象你每天记录城市气温，数据里总有"噪声"——某天突然异常寒冷，或莫名其妙地偏热。移动平均的直觉是：今天的波动，可能和昨天、前天发生的随机扰动有关，而不仅仅是数值本身。

探索概念结构：移动平均模型（MA 模型）描述的正是这种逻辑——当前时刻的值，由当前的随机误差加上过去若干个随机误差的加权和共同决定。

一个 $q$ 阶移动平均模型，记作 $\mathrm{MA}(q)$，定义为：

$$X_t = \mu + \varepsilon_t + \theta_1\varepsilon_{t-1} + \theta_2\varepsilon_{t-2} + \cdots + \theta_q\varepsilon_{t-q}$$

其中：

  • $X_t$ 是第 $t$ 时刻的观测值，$\mu$ 是序列均值
  • $\varepsilon_t, \varepsilon_{t-1}, \ldots$ 是各时刻的随机误差（噪声），均值为 $0$
  • $\theta_1, \ldots, \theta_q$ 是各误差项的权重系数

    • 核心规律：MA 模型与自回归（AR）模型的本质区别在于：AR 用过去的真实值预测未来，MA 用过去的误差来预测。MA 模型对"冲击"的记忆是有限的——一次随机扰动最多向后传播 $q$ 步，之后影响完全消失，这叫做有限记忆性。

    练习题：某城市日降雨量偏差满足 $\mathrm{MA}(1)$ 模型：

    $$X_t = \varepsilon_t + 0.6\,\varepsilon_{t-1}$$

    若昨天的随机误差为 $\varepsilon_{t-1} = 3\,\mathrm{mm}$，今天的随机误差为 $\varepsilon_t = -1\,\mathrm{mm}$，请计算今天的预测偏差 $X_t$。
