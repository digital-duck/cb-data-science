Quartiles

Definition. Let $X$ be a dataset of $n$ real observations arranged in non-decreasing order: $x_{(1)} \le x_{(2)} \le \cdots \le x_{(n)}$. The quartiles partition this ordered dataset into four groups of approximately equal size. Specifically, the first quartile $Q_1$, second quartile $Q_2$ (the median), and third quartile $Q_3$ are the values at the 25th, 50th, and 75th percentiles, respectively. A common interpolation rule defines the $p$-th percentile position as $L = p(n+1)/100$; if $L$ is not an integer, one linearly interpolates between the observations at positions $\lfloor L \rfloor$ and $\lceil L \rceil$.

The interquartile range (IQR) is defined as

$$\mathrm{IQR} = Q_3 - Q_1.$$

It measures the spread of the central 50 % of the data and is robust to extreme values, unlike the full range $x_{(n)} - x_{(1)}$.

Worked example. Consider the dataset $\{3, 7, 8, 12, 14, 17, 21, 25\}$, so $n = 8$.

  • $Q_2$: the median lies between the 4th and 5th values, giving $Q_2 = (12 + 14)/2 = 13$.
  • $Q_1$: apply the rule to the lower half $\{3, 7, 8, 12\}$; the median of this half is $(7+8)/2 = 7.5$, so $Q_1 = 7.5$.
  • $Q_3$: the upper half is $\{14, 17, 21, 25\}$; its median is $(17+21)/2 = 19$, so $Q_3 = 19$.
  • $\mathrm{IQR} = 19 - 7.5 = 11.5$.

    • Theorem (Tukey fence criterion). An observation $x$ is a mild outlier if it lies outside the interval $[Q_1 - 1.5\,\mathrm{IQR},\; Q_3 + 1.5\,\mathrm{IQR}]$, and an extreme outlier if it lies outside $[Q_1 - 3\,\mathrm{IQR},\; Q_3 + 3\,\mathrm{IQR}]$. These fences form the basis of the standard box-and-whisker plot and follow directly from the empirical observation that, for normally distributed data, fewer than 0.7 % of values fall beyond the mild fence.

    Lab cell.

    import numpy as np
from sympy.stats import Normal, cdf
data = [3, 7, 8, 12, 14, 17, 21, 25]
q1, q2, q3 = np.percentile(data, [25, 50, 75])
iqr = q3 - q1
lower_fence = q1 - 1.5 * iqr
upper_fence = q3 + 1.5 * iqr
print(f"Q1={q1}, Q2={q2}, Q3={q3}, IQR={iqr}")
print(f"Tukey fences: [{lower_fence}, {upper_fence}]")
outliers = [x for x in data if x < lower_fence or x > upper_fence]
print(f"Outliers: {outliers}")
