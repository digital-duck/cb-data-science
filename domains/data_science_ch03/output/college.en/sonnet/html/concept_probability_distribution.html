Probability Distribution

Definition. Let $S$ be a sample space associated with a random experiment. A probability distribution is a function $P$ that assigns to every event $A \subseteq S$ a real number satisfying the Kolmogorov axioms: (i) $P(A) \geq 0$, (ii) $P(S) = 1$, and (iii) for any countable collection of mutually exclusive events $A_1, A_2, \ldots$,

$$P\!\left(\bigcup_{i=1}^{\infty} A_i\right) = \sum_{i=1}^{\infty} P(A_i).$$

When $S$ is finite or countably infinite, the distribution is described completely by a probability mass function (PMF) $p(x) = P(X = x)$, where $X$ is a discrete random variable taking values in $S$. The PMF must satisfy $p(x) \geq 0$ for all $x$ and $\sum_{x \in S} p(x) = 1$; together these conditions are exactly equivalent to the Kolmogorov axioms in the discrete setting.

Worked Example. Suppose a fair six-sided die is rolled once. The sample space is $S = \{1,2,3,4,5,6\}$ and the PMF is $p(x) = \tfrac{1}{6}$ for each $x \in S$. Normalization holds because $\sum_{x=1}^{6} \tfrac{1}{6} = 1$. The probability of rolling an even number is

$$P(X \in \{2,4,6\}) = p(2) + p(4) + p(6) = \frac{1}{6} + \frac{1}{6} + \frac{1}{6} = \frac{1}{2}.$$

Note that the assignment $p(x) = \tfrac{1}{6}$ is not forced by the sample space alone; it encodes the physical assumption of fairness. A loaded die would yield a different PMF over the same $S$.

Key Theorem (Law of Total Probability). If $\{B_1, B_2, \ldots, B_n\}$ is a partition of $S$, then for any event $A$,

$$P(A) = \sum_{i=1}^{n} P(A \mid B_i)\,P(B_i).$$

This theorem allows marginal probabilities to be computed by conditioning on a convenient auxiliary partition, and it forms the backbone of Bayesian inference.

Lab Cell.

from sympy import Rational

# PMF for a fair six-sided die
pmf = {x: Rational(1, 6) for x in range(1, 7)}

# Verify normalization
print(sum(pmf.values()))                          # → 1

# P(X is even)
print(sum(pmf[x] for x in pmf if x % 2 == 0))   # → 1/2
