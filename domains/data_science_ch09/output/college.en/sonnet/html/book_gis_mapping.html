What GIS Mapping Achieves

Geographic Information System (GIS) mapping is the culmination of a conceptual journey that weaves together coordinate geometry, topological reasoning, and computational representation. Formally, a GIS map is a function

$$\phi: \mathcal{F} \times \mathcal{C} \to \mathcal{R}^2$$

that sends each geographic feature $f \in \mathcal{F}$ (a road, a watershed boundary, a census tract) paired with a coordinate reference system $c \in \mathcal{C}$ to a planar representation in $\mathcal{R}^2$. This deceptively simple definition conceals layers of mathematical richness: $\phi$ must be consistent with a map projection (a smooth, structure-preserving map from the sphere $S^2$ to the plane), it must respect topological adjacency, and it must compose gracefully across layers of heterogeneous data.

The natural endpoint quality of GIS mapping arises because it is the operation that makes abstraction visible. Every prior concept in this book — coordinate systems, projections, spatial indexing, vector and raster models — has been preparation for the moment when spatial relationships become queryable, renderable, and actionable on a shared canvas.

Worked Example

Suppose we wish to overlay two layers: a polygon layer $L_P$ of municipal boundaries (stored as lists of latitude-longitude vertices) and a point layer $L_Q$ of hospital locations. Both arrive in WGS 84 (EPSG:4326). To compute which hospitals fall within each municipality, we first reproject to a planar equal-area system — say, EPSG:3857 — using the Mercator projection equations

$$x = R\,\lambda, \qquad y = R\ln\!\left[\tan\!\left(\frac{\pi}{4}+\frac{\varphi}{2}\right)\right],$$

where $R$ is Earth's mean radius, $\lambda$ is longitude, and $\varphi$ is latitude. After reprojection, the spatial join reduces to a sequence of point-in-polygon tests, each solvable in $O(\log n)$ time with a prebuilt $R$-tree index.

Key Theorem (Layer Composition)

Let $\phi_1, \phi_2$ be two GIS maps defined on a common CRS. Their overlay $\phi_1 \cap \phi_2$ produces a new layer whose feature set is the set-theoretic intersection of the corresponding geometries. If both layers are topologically valid (no self-intersections, no unclosed rings), then $\phi_1 \cap \phi_2$ is computable in $O((n + k)\log n)$ time via a plane-sweep algorithm, where $n$ is the total vertex count and $k$ is the number of intersection events.

Lab Cell

from sympy import symbols, tan, pi, ln, simplify

lam, phi, R = symbols('lambda phi R', real=True)
x_merc = R * lam
y_merc = R * ln(tan(pi/4 + phi/2))

# Verify that dy/dphi > 0 everywhere (conformal property)
from sympy import diff
dy_dphi = diff(y_merc, phi)
print(simplify(dy_dphi))   # Expected: R / cos(phi)

Running this cell confirms that the Mercator projection is conformal — it preserves local angles — which is precisely why it remains the projection of choice for web map tiles despite its well-known area distortions at high latitudes.
