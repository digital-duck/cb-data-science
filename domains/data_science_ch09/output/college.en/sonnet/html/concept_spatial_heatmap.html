Spatial Heatmap

Definition. A spatial heatmap is a function $H: \Omega \to \mathbb{R}$ defined on a bounded spatial domain $\Omega \subseteq \mathbb{R}^2$, together with a visualization scheme that encodes the scalar value $H(x,y)$ as a color at each point $(x,y) \in \Omega$. Formally, a color map $\mathcal{C}: \mathbb{R} \to [0,1]^3$ maps each scalar to an RGB triple, producing an image that allows a human observer to perceive the continuous field $H$ at a glance. In discrete applications, $H$ is sampled on a grid $\{(x_i, y_j)\}$ of size $m \times n$, yielding a matrix $\mathbf{H} \in \mathbb{R}^{m \times n}$ whose entry $H_{ij} = H(x_i, y_j)$ represents the field intensity at cell $(i,j)$.

Worked Example. Consider a thin metal plate occupying $\Omega = [0,1]^2$ whose steady-state temperature is governed by a known analytic function:

$$T(x,y) = \sin(\pi x)\,\sin(\pi y), \quad (x,y)\in[0,1]^2.$$

Sample this function on a $50\times50$ uniform grid: $x_i = i/49$, $y_j = j/49$ for $0 \le i,j \le 49$. The matrix $\mathbf{T}$ with $T_{ij} = \sin(\pi x_i)\sin(\pi y_j)$ attains its maximum value of $1$ at the plate center $(0.5, 0.5)$ and vanishes on all four edges, consistent with Dirichlet boundary conditions $T = 0$ on $\partial\Omega$. Rendering $\mathbf{T}$ with a diverging color map immediately reveals this bowl-shaped profile.

Key Theorem (Extrema Correspondence). Let $H \in C(\overline{\Omega})$ be continuous on a compact domain. Then the global maximum and minimum of $H$ correspond to the brightest and darkest cells in any strictly monotone color map $\mathcal{C}$. Consequently, visual inspection of the heatmap locates the extrema of $H$ up to the grid resolution $\delta = \max(\Delta x, \Delta y)$.

Proof sketch. Continuity on a compact set guarantees $H$ attains its supremum and infimum (Extreme Value Theorem). A strictly monotone $\mathcal{C}$ is an order-preserving bijection, so the color extremes coincide exactly with the scalar extremes. $\square$

Lab Cell.

import sympy as sp
import numpy as np
import matplotlib.pyplot as plt

x, y = sp.symbols('x y')
T_sym = sp.sin(sp.pi * x) * sp.sin(sp.pi * y)
T_func = sp.lambdify((x, y), T_sym, 'numpy')

xs = np.linspace(0, 1, 50)
ys = np.linspace(0, 1, 50)
X, Y = np.meshgrid(xs, ys)
Z = T_func(X, Y)

plt.figure(figsize=(5, 4))
plt.pcolormesh(X, Y, Z, cmap='RdBu_r', shading='auto')
plt.colorbar(label='T(x,y)')
plt.title('Steady-state temperature heatmap')
plt.xlabel('x'); plt.ylabel('y')
plt.tight_layout(); plt.show()

Running this cell produces a symmetric heatmap confirming that temperature peaks at the plate center and satisfies the zero-boundary condition on all sides.
