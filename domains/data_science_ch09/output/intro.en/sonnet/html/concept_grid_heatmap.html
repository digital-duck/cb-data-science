Grid Heatmap

Definition. A grid heatmap is a two-dimensional array visualization in which a scalar value $f(i,j)$ is encoded as a color intensity at the cell located in row $i$ and column $j$ of a rectangular grid. Formally, given a matrix $A \in \mathbb{R}^{m \times n}$, a heatmap assigns to each entry $a_{ij}$ a color $c_{ij} = \phi(a_{ij})$, where $\phi : \mathbb{R} \to \mathcal{C}$ is a colormap—a monotone mapping from the real line into a perceptually ordered color space $\mathcal{C}$. The colormap is typically normalized so that the minimum value in $A$ maps to one extreme of the palette and the maximum maps to the other.

Worked Example. Consider the $3 \times 3$ matrix

$$A = \begin{pmatrix} 1 & 4 & 2 \\ 8 & 5 & 3 \\ 6 & 7 & 9 \end{pmatrix}.$$

To render a heatmap, each entry is linearly rescaled to $[0,1]$ via

$$\tilde{a}_{ij} = \frac{a_{ij} - a_{\min}}{a_{\max} - a_{\min}},$$

where $a_{\min} = 1$ and $a_{\max} = 9$. The entry $a_{23} = 3$ maps to $\tilde{a}_{23} = \frac{3-1}{9-1} = 0.25$, rendered as a relatively cool color, while $a_{33} = 9$ maps to $\tilde{a}_{33} = 1.0$, rendered as the hottest color. This immediately reveals that the bottom-right region of $A$ contains the largest values.

Key Theorem (Colormap Monotonicity). Let $\phi$ be a strictly monotone colormap and let $\preceq$ denote perceptual ordering on $\mathcal{C}$. Then for all $i, j, k, l$,

$$a_{ij} < a_{kl} \implies \phi(a_{ij}) \prec \phi(a_{kl}).$$

This property guarantees that relative magnitudes are faithfully represented: a viewer's ranking of colors by intensity corresponds exactly to the numerical ranking of the underlying values.

Lab Cell.

import numpy as np
import matplotlib.pyplot as plt
from sympy import Matrix

A = Matrix([[1, 4, 2], [8, 5, 3], [6, 7, 9]])
data = np.array(A.tolist(), dtype=float)

fig, ax = plt.subplots()
im = ax.imshow(data, cmap='viridis')
plt.colorbar(im, ax=ax, label='Value')
for i in range(3):
    for j in range(3):
        ax.text(j, i, int(data[i, j]),
                ha='center', va='center', color='white')
ax.set_title('Grid Heatmap of A')
plt.tight_layout()
plt.show()

Running this cell produces a $3 \times 3$ grid in which each cell is shaded according to its entry. The viridis colormap is perceptually uniform, ensuring that equal steps in value correspond to equal steps in perceived brightness—a property essential for accurate quantitative comparison across the grid.
