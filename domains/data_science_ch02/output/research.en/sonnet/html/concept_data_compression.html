Data Compression

Definition. Given a source alphabet $\mathcal{X}$ with probability distribution $P$, data compression is the process of mapping sequences of source symbols to shorter binary codewords, thereby reducing the average number of bits required for storage or transmission. A lossless compression scheme is a bijective mapping $C : \mathcal{X}^ \to \{0,1\}^$ such that the original sequence can be recovered exactly from its encoding. The fundamental quantity governing how far compression can proceed is the Shannon entropy:

$$H(X) = -\sum_{x \in \mathcal{X}} P(x) \log_2 P(x) \quad \text{(bits per symbol)}.$$

Entropy measures the irreducible average information content of the source; no lossless code can achieve an average codeword length below $H(X)$.

Worked Example. Suppose a source emits four symbols with probabilities $P(a)=\tfrac{1}{2}$, $P(b)=\tfrac{1}{4}$, $P(c)=\tfrac{1}{8}$, $P(d)=\tfrac{1}{8}$. The entropy is:

$$H(X) = -\tfrac{1}{2}\log_2\tfrac{1}{2} - \tfrac{1}{4}\log_2\tfrac{1}{4} - 2\cdot\tfrac{1}{8}\log_2\tfrac{1}{8} = \tfrac{1}{2}+\tfrac{2}{4}+\tfrac{3}{8}+\tfrac{3}{8} = 1.75 \text{ bits}.$$

A Huffman code assigns $a \mapsto 0$, $b \mapsto 10$, $c \mapsto 110$, $d \mapsto 111$, yielding average length $\bar{L} = \tfrac{1}{2}(1)+\tfrac{1}{4}(2)+\tfrac{1}{8}(3)+\tfrac{1}{8}(3) = 1.75$ bits — achieving the entropy bound exactly because all probabilities are negative powers of two.

Key Theorem (Shannon's Source Coding Theorem). For a discrete memoryless source with entropy $H(X)$, there exists a uniquely decodable code with average codeword length $\bar{L}$ satisfying:

$$H(X) \leq \bar{L} < H(X) + 1.$$

Moreover, no uniquely decodable code can achieve $\bar{L} < H(X)$. The upper bound is always achieved by Huffman coding, making it optimal among symbol-by-symbol schemes.

Lab Cell.

from sympy import Rational, log, N

probs = [Rational(1,2), Rational(1,4), Rational(1,8), Rational(1,8)]
H = -sum(p * log(p, 2) for p in probs)

lengths = [1, 2, 3, 3]
L_bar = sum(p * l for p, l in zip(probs, lengths))

print("Entropy H(X) =", N(H, 4), "bits")
print("Average codeword length =", N(L_bar, 4), "bits")
print("Bound satisfied:", H <= L_bar < H + 1)

Running this cell confirms $H(X) = \bar{L} = 1.75$ bits and that the Huffman code achieves the lower bound of Shannon's theorem.
