Regular Expressions

Definition. A regular expression (regex) over a finite alphabet $\Sigma$ is a symbolic pattern that denotes a regular language — a set of strings. Formally, regular expressions are defined inductively:

  • $\emptyset$ denotes the empty language; $\varepsilon$ denotes $\{\varepsilon\}$ (the language containing only the empty string).
  • For any symbol $a \in \Sigma$, the expression $a$ denotes $\{a\}$.
  • If $r$ and $s$ are regular expressions denoting languages $L(r)$ and $L(s)$, then:

    • - Alternation $r \mid s$ denotes $L(r) \cup L(s)$, - Concatenation $rs$ denotes $\{xy \mid x \in L(r),\, y \in L(s)\}$, - Kleene star $r^*$ denotes $\bigcup_{n=0}^{\infty} L(r)^n$, i.e., zero or more repetitions of strings in $L(r)$.

    No other expressions are regular. This recursive definition ensures that every regular expression corresponds to a language recognizable by a finite automaton.

    Worked Example. Let $\Sigma = \{0, 1\}$. Consider the regular expression $r = (0 \mid 1)^ 1 (0 \mid 1)^$. The language $L(r)$ is the set of all binary strings containing at least one $1$. To verify: any string $w \in L(r)$ can be decomposed as $w = u\,1\,v$ where $u, v \in \{0,1\}^$; conversely, every binary string with at least one $1$ admits such a decomposition. The complement $\overline{L(r)}$ is $\{0^n \mid n \geq 0\}$, described by $0^$.

    Key Theorem (Kleene's Theorem). A language $L \subseteq \Sigma^*$ is regular if and only if it is recognized by a deterministic finite automaton (DFA). Consequently, the class of regular languages is closed under union, concatenation, complementation, and Kleene star. The proof proceeds in two directions: given a regex, construct an $\varepsilon$-NFA by structural induction (Thompson's construction), then convert to a DFA via the subset construction; given a DFA, derive a regex by state elimination.

    Lab Cell.

    import re

pattern = re.compile(r'^(0|1)*1(0|1)*$')   # binary strings containing a 1

test_strings = ["0", "00", "1", "101", "010", "000"]
for s in test_strings:
    matched = bool(pattern.match(s))
    print(f"  {s!r:>6}  →  {'accepted' if matched else 'rejected'}")

    Running this cell prints rejected for "0" and "00" and accepted for every string containing at least one 1, confirming the semantic claim above.
