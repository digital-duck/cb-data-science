Large Language Model

Definition. A large language model (LLM) is a parametric probability distribution $p_\theta$ over sequences of tokens drawn from a finite vocabulary $\mathcal{V}$. Given a context sequence $x_{1:t} = (x_1, x_2, \ldots, x_t)$ with each $x_i \in \mathcal{V}$, the model factorizes the joint distribution autoregressively:

$$p_\theta(x_{1:T}) = \prod_{t=1}^{T} p_\theta(x_t \mid x_{1:t-1}).$$

Each conditional factor is computed by a deep neural network — in contemporary practice, the Transformer architecture — whose $|\theta|$ parameters number in the billions. Training minimizes the negative log-likelihood (equivalently, cross-entropy loss) over a corpus $\mathcal{D}$:

$$\mathcal{L}(\theta) = -\frac{1}{|\mathcal{D}|} \sum_{(x_{1:T}) \in \mathcal{D}} \sum_{t=1}^{T} \log p_\theta(x_t \mid x_{1:t-1}).$$

The term large is deliberately relative: it marks the empirical threshold above which models exhibit qualitative emergent capabilities absent in smaller counterparts.

Worked Example. Suppose $\mathcal{V} = \{\texttt{cat}, \texttt{sat}, \texttt{on}, \texttt{mat}\}$ and the context is $x_{1:2} = (\texttt{cat}, \texttt{sat})$. An LLM assigns a probability vector over $\mathcal{V}$ for position $t = 3$:

$$p_\theta(\cdot \mid \texttt{cat}, \texttt{sat}) = [0.02,\ 0.03,\ 0.90,\ 0.05].$$

Generation by greedy decoding selects $x_3 = \arg\max p_\theta(\cdot \mid x_{1:2}) = \texttt{on}$. Sampling instead draws $x_3 \sim p_\theta(\cdot \mid x_{1:2})$, introducing stochasticity controlled by a temperature parameter $\tau$ that rescales logits as $z_i \leftarrow z_i / \tau$ before the softmax.

Key Theorem (Universal Approximation for Sequences). For any distribution $q$ over $\mathcal{V}^*$ with finite entropy and any $\varepsilon > 0$, there exists a Transformer $p_\theta$ with sufficiently many layers and heads such that $D_{\mathrm{KL}}(q \,\|\, p_\theta) < \varepsilon$. This result underpins the empirical scaling laws observed by Kaplan et al. (2020), where test loss decreases as a power law in $|\theta|$, dataset size, and compute.

Lab Cell.

import sympy as sp

# Softmax at temperature tau
tau = sp.Symbol('tau', positive=True)
z = sp.Matrix([2, 1, 4, 1])          # raw logits
z_scaled = z / tau
exp_z = z_scaled.applyfunc(sp.exp)
probs = exp_z / exp_z.dot(sp.ones(4, 1))

# Evaluate at tau=1
p_numeric = probs.subs(tau, 1).applyfunc(sp.N)
print("Softmax probabilities:", p_numeric.T)

Running this cell at $\tau = 1$ recovers the normalized probability vector; reducing $\tau \to 0$ sharpens the distribution toward a one-hot argmax, while $\tau \to \infty$ flattens it toward uniform — illustrating the temperature–diversity trade-off central to LLM decoding strategies.
