Neural Network

Definition. A neural network is a parameterized function $f_\theta : \mathbb{R}^n \to \mathbb{R}^m$ composed of alternating linear maps and nonlinear activations. A feedforward network with $L$ layers is defined by the recurrence

$$ \mathbf{a}^{(0)} = \mathbf{x}, \qquad \mathbf{a}^{(\ell)} = \sigma\!\left(W^{(\ell)}\mathbf{a}^{(\ell-1)} + \mathbf{b}^{(\ell)}\right), \quad \ell = 1, \dots, L, $$

where $W^{(\ell)} \in \mathbb{R}^{d_\ell \times d_{\ell-1}}$ is the weight matrix, $\mathbf{b}^{(\ell)} \in \mathbb{R}^{d_\ell}$ is the bias vector, and $\sigma$ is a scalar activation applied elementwise. The output is $f_\theta(\mathbf{x}) = \mathbf{a}^{(L)}$, and the full parameter vector is $\theta = \{W^{(\ell)}, \mathbf{b}^{(\ell)}\}_{\ell=1}^{L}$.

Worked Example. Consider a two-layer network with architecture $2 \to 3 \to 1$ and ReLU activation $\sigma(z) = \max(0, z)$. Let

$$ W^{(1)} = \begin{pmatrix} 1 & 0 \\ -1 & 1 \\ 0 & 1 \end{pmatrix}, \quad \mathbf{b}^{(1)} = \mathbf{0}, \quad W^{(2)} = \begin{pmatrix} 1 & 1 & -1 \end{pmatrix}, \quad b^{(2)} = 0. $$

For input $\mathbf{x} = (2, -1)^\top$, the hidden pre-activation is $W^{(1)}\mathbf{x} = (2, -3, -1)^\top$. After ReLU: $\mathbf{a}^{(1)} = (2, 0, 0)^\top$. The output is $f_\theta(\mathbf{x}) = W^{(2)}\mathbf{a}^{(1)} = 2$.

Key Theorem (Universal Approximation). Let $\sigma$ be any continuous, non-polynomial activation function. Then for every continuous function $g : [0,1]^n \to \mathbb{R}$ and every $\varepsilon > 0$, there exists a single-hidden-layer network $f_\theta$ such that

$$ \sup_{\mathbf{x} \in [0,1]^n} |f_\theta(\mathbf{x}) - g(\mathbf{x})| < \varepsilon. $$

The proof sketch proceeds by showing that finite linear combinations of shifted copies of $\sigma$ are dense in $C([0,1]^n)$ under the supremum norm; because $\sigma$ is non-polynomial, no finite combination can vanish identically, which supplies the necessary density. Crucially, the theorem guarantees existence but provides no bound on the required width or a practical learning algorithm.

Lab Cell.

import sympy as sp

x1, x2 = sp.symbols('x1 x2')
x = sp.Matrix([x1, x2])

W1 = sp.Matrix([[1, 0], [-1, 1], [0, 1]])
b1 = sp.zeros(3, 1)
W2 = sp.Matrix([[1, 1, -1]])

relu = lambda v: v.applyfunc(lambda z: sp.Max(0, z))

a1 = relu(W1 * x + b1)
output = W2 * a1
sp.pprint(sp.simplify(output[0, 0]))

Running this cell with $\mathbf{x} = (2, -1)^\top$ recovers the scalar output $2$, confirming the worked example symbolically.
