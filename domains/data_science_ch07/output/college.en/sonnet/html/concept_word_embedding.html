Word Embedding

Definition. A word embedding is a function $\phi: \mathcal{V} \to \mathbb{R}^d$ that maps each word in a finite vocabulary $\mathcal{V}$ to a dense vector in $d$-dimensional Euclidean space, where $d \ll |\mathcal{V}|$. The embedding is learned so that geometric relationships in $\mathbb{R}^d$ reflect semantic or syntactic relationships among words. Formally, if $w_i, w_j \in \mathcal{V}$ are semantically similar, we expect $\|\phi(w_i) - \phi(w_j)\|_2$ to be small. This contrasts with one-hot encoding, in which every word is represented by a standard basis vector $e_i \in \mathbb{R}^{|\mathcal{V}|}$; under one-hot encoding, all inter-word distances are equal and no semantic structure is encoded.

Worked Example. Consider a toy vocabulary $\mathcal{V} = \{\text{king}, \text{queen}, \text{man}, \text{woman}\}$ and suppose a learned embedding in $\mathbb{R}^2$ yields

$$\phi(\text{king}) = \begin{pmatrix}0.9\\0.1\end{pmatrix},\quad \phi(\text{queen}) = \begin{pmatrix}0.9\\0.9\end{pmatrix},\quad \phi(\text{man}) = \begin{pmatrix}0.1\\0.1\end{pmatrix},\quad \phi(\text{woman}) = \begin{pmatrix}0.1\\0.9\end{pmatrix}.$$

Computing the analogy vector $\phi(\text{king}) - \phi(\text{man}) + \phi(\text{woman}) = (0.9, 0.9)^\top = \phi(\text{queen})$ recovers the gender analogy $\text{king} - \text{man} + \text{woman} \approx \text{queen}$ exactly. Real embeddings exhibit this structure approximately, not exactly, but the principle generalises to thousands of dimensions and millions of words.

Key Theorem (Distributional Hypothesis, Firth 1957; formalised by Levy & Goldberg 2014). The skip-gram model with negative sampling (Word2Vec) implicitly factorises the shifted pointwise mutual information matrix $M_{ij} = \mathrm{PMI}(w_i, c_j) - \log k$, where $c_j$ ranges over context words and $k$ is the number of negative samples. Consequently, the optimal embedding vectors satisfy $\phi(w_i)^\top \phi(c_j) \approx \mathrm{PMI}(w_i, c_j) - \log k$, grounding the geometric intuition in an information-theoretic objective.

Lab Cell.

import numpy as np
from sympy import Matrix, sqrt, Rational

# Toy embedding matrix: rows are word vectors
E = Matrix([
    [Rational(9,10), Rational(1,10)],   # king
    [Rational(9,10), Rational(9,10)],   # queen
    [Rational(1,10), Rational(1,10)],   # man
    [Rational(1,10), Rational(9,10)],   # woman
])

# Cosine similarity between king and queen
v1, v2 = E.row(0), E.row(1)
cos_sim = v1.dot(v2) / (sqrt(v1.dot(v1)) * sqrt(v2.dot(v2)))
print("cos(king, queen) =", cos_sim)   # close to 1

# Analogy: king - man + woman
analogy = E.row(0) - E.row(2) + E.row(3)
print("king - man + woman =", analogy) # should equal queen

Running this cell confirms $\cos(\phi(\text{king}), \phi(\text{queen})) = 1$ in this idealised example, and that the analogy arithmetic closes exactly. In practice, embeddings trained on large corpora achieve cosine similarities above $0.7$ for such canonical analogies.
