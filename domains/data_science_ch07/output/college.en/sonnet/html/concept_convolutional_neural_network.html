Convolutional Neural Network

Definition. A convolutional neural network (CNN) is a feedforward neural network in which at least one layer computes a discrete convolution rather than a general matrix–vector product. Given an input feature map $\mathbf{X} \in \mathbb{R}^{H \times W}$ and a learnable filter $\mathbf{K} \in \mathbb{R}^{k \times k}$, the output feature map $\mathbf{Y}$ is defined entry-wise by

$$Y[i,j] = \sum_{m=0}^{k-1}\sum_{n=0}^{k-1} K[m,n]\, X[i+m,\, j+n] + b,$$

where $b \in \mathbb{R}$ is a bias term. Stacking multiple filters $\mathbf{K}^{(c)}$, $c = 1,\dots,C$, produces $C$ feature maps, each detecting a distinct spatial pattern. Hyperparameters such as stride and padding control the spatial extent of the output, and an elementwise nonlinearity applied after each convolution introduces the representational capacity needed for deep architectures; these details are treated in subsequent sections. The present section focuses exclusively on the convolution operation itself.

Worked example. Let $\mathbf{X}$ be the $4\times4$ matrix with all entries equal to $1$ except $X[1,1]=5$, and let $\mathbf{K}$ be the $3\times3$ identity-edge filter

$$\mathbf{K} = \begin{pmatrix} -1 & -1 & -1 \\ -1 & 8 & -1 \\ -1 & -1 & -1 \end{pmatrix}.$$

With stride $s=1$ and no padding the output is $2\times2$. At position $(0,0)$, the eight neighbours of $X[1,1]$ each contribute $-1$, and the centre contributes $8\cdot5 = 40$, giving $Y[0,0] = 40 - 8 = 32$. Every other output position sums eight copies of $1$ with one copy of $1$ at the centre: $Y[0,1]=Y[1,0]=Y[1,1]=8-8=0$. The large response at $(0,0)$ reveals that the filter localises the intensity anomaly at $X[1,1]$, demonstrating how convolution acts as a spatially-localised feature detector.

Key theorem (parameter sharing and translational equivariance). If the same filter $\mathbf{K}$ is applied at every spatial location, then shifting the input by $(\Delta i, \Delta j)$ shifts the output by the same amount: $\mathcal{F}[\mathbf{X}(\cdot - \boldsymbol{\Delta})] = \mathcal{F}[\mathbf{X}](\cdot - \boldsymbol{\Delta})$. Consequently, a CNN with $C$ filters of size $k\times k$ requires only $C k^2$ weights per layer—independent of $H$ and $W$—making it far more parameter-efficient than a fully-connected layer, which would require $HW \times HW$ weights.

Lab cell.

import sympy as sp

# Symbolic 1-D convolution
x = sp.Matrix([1, 1, 5, 1])
k = sp.Matrix([-1, 8, -1])
output = [sum(k[m] * x[i + m] for m in range(3)) for i in range(2)]
sp.pprint(sp.Matrix(output))   # Expected: [-2, 34]
