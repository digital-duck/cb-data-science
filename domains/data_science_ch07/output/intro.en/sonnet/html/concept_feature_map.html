Feature Map

Definition. Let $\mathcal{X}$ be an input space and $\mathcal{H}$ a Hilbert space. A feature map is a function

$$\phi : \mathcal{X} \to \mathcal{H}$$

that embeds each input $x \in \mathcal{X}$ into $\mathcal{H}$ as a vector $\phi(x)$, called the feature vector. The inner product $\langle \phi(x), \phi(x') \rangle_{\mathcal{H}}$ then defines a kernel

$$k(x, x') = \langle \phi(x), \phi(x') \rangle_{\mathcal{H}},$$

allowing geometric operations — distance, projection, linear separation — to be performed in $\mathcal{H}$ even when $\mathcal{X}$ itself carries no natural linear structure.

Worked Example. Consider $\mathcal{X} = \mathbb{R}$ and the polynomial feature map of degree 2:

$$\phi(x) = \begin{pmatrix} 1 \\ x \\ x^2 \end{pmatrix} \in \mathbb{R}^3.$$

Take $x = 2$ and $x' = 3$. Then

$$\phi(2) = (1,\, 2,\, 4)^\top, \qquad \phi(3) = (1,\, 3,\, 9)^\top,$$

and the induced kernel evaluates to

$$k(2, 3) = \langle \phi(2), \phi(3) \rangle = 1 \cdot 1 + 2 \cdot 3 + 4 \cdot 9 = 1 + 6 + 36 = 43.$$

One can verify algebraically that $k(x, x') = (1 + x x')^2 - x^2 {x'}^2 / \text{(some form)}$; more cleanly, the homogeneous degree-2 map $\phi(x) = (x, x^2)^\top$ gives $k(x,x') = xx' + x^2 x'^2$, illustrating how the choice of $\phi$ determines which interactions are captured.

Key Theorem (Mercer's Theorem, sketch). A symmetric, positive semi-definite kernel $k : \mathcal{X} \times \mathcal{X} \to \mathbb{R}$ — meaning $\sum_{i,j} c_i c_j k(x_i, x_j) \geq 0$ for all finite collections and real coefficients — is always realizable as an inner product in some Hilbert space $\mathcal{H}$. That is, there exists a feature map $\phi$ such that $k(x, x') = \langle \phi(x), \phi(x') \rangle_{\mathcal{H}}$. This guarantees that kernels such as the Gaussian $k(x,x') = \exp\!\bigl(-\|x - x'\|^2 / 2\sigma^2\bigr)$ correspond to valid (infinite-dimensional) feature spaces, enabling the kernel trick: algorithms that depend only on inner products can operate implicitly in $\mathcal{H}$ without ever computing $\phi$ explicitly.

Lab Cell.

from sympy import symbols, Matrix, simplify, expand

x, xp = symbols('x xp')

phi  = Matrix([1, x,  x**2])
phip = Matrix([1, xp, xp**2])

k = phi.dot(phip)
print("k(x, x') =", expand(k))

print("k(2, 3)  =", k.subs({x: 2, xp: 3}))

Running this cell confirms $k(x,x') = 1 + xx' + x^2 x'^2$ and reproduces the value $43$ computed above.
