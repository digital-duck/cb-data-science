Semantic Segmentation

Definition. Given an image $I : \Omega \to \mathbb{R}^3$, where $\Omega \subset \mathbb{Z}^2$ is the discrete pixel grid, semantic segmentation is the task of learning a function $f_\theta : \mathbb{R}^3 \to \{1, \dots, K\}$ such that every pixel $\mathbf{p} \in \Omega$ is assigned a class label $\hat{y}_\mathbf{p} = f_\theta(I(\mathbf{p}))$, or more precisely, a label derived from a local neighbourhood context $\mathcal{N}(\mathbf{p})$. Unlike image classification, which produces a single label for the entire image, semantic segmentation produces a dense label map $\hat{Y} : \Omega \to \{1, \dots, K\}$ of the same spatial resolution as $I$.

Worked Example. Consider a $4 \times 4$ grayscale image containing a $2 \times 2$ foreground object (class 1, "circle") centred on a background (class 0). The ground-truth label map $Y$ assigns $y_\mathbf{p} = 1$ to the four central pixels and $y_\mathbf{p} = 0$ elsewhere. A segmentation model predicts $\hat{Y}$; suppose it correctly labels 3 of the 4 foreground pixels and all 12 background pixels. The standard evaluation metric is the Intersection over Union (IoU) per class:

$$\text{IoU}_k = \frac{|S_k \cap \hat{S}_k|}{|S_k \cup \hat{S}_k|}$$

where $S_k = \{\mathbf{p} : y_\mathbf{p} = k\}$ and $\hat{S}_k = \{\mathbf{p} : \hat{y}_\mathbf{p} = k\}$. For the foreground, $|S_1 \cap \hat{S}_1| = 3$ and $|S_1 \cup \hat{S}_1| = 4$, giving $\text{IoU}_1 = 0.75$. The mean IoU (mIoU) averages across all $K$ classes.

Key Theorem (Fully Convolutional Representation). Any convolutional neural network that maps an input tensor of shape $H \times W \times 3$ to a feature map of shape $H' \times W' \times C$ can be extended to a fully convolutional network (FCN) by replacing all fully-connected layers with $1 \times 1$ convolutions and appending a bilinear upsampling stage, producing a dense prediction of shape $H \times W \times K$. The per-pixel cross-entropy loss is then:

$$\mathcal{L}(\theta) = -\frac{1}{|\Omega|} \sum_{\mathbf{p} \in \Omega} \log \hat{p}_{y_\mathbf{p}}(\mathbf{p};\theta)$$

where $\hat{p}_k(\mathbf{p};\theta) = \text{softmax}(f_\theta(\mathcal{N}(\mathbf{p})))_k$.
