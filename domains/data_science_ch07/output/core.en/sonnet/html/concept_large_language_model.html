Large Language Model

You already know that a language model tries to predict the next word in a sequence. A large language model (LLM) takes that same idea and scales it up dramatically — billions of learned numbers, trained on hundreds of billions of words — until something remarkable happens: the model doesn't just complete sentences, it reasons, translates, summarizes, and writes code.

How the scale creates capability. An LLM is built on a structure called a transformer. At its core, the transformer learns to assign attention weights: given every word already in the context, how much should the model "look at" each earlier word when deciding what comes next? Formally, for a sequence of tokens $x_1, x_2, \ldots, x_n$, the model learns a conditional probability

$$P(x_{n+1} \mid x_1, x_2, \ldots, x_n).$$

Training adjusts billions of internal parameters $\theta$ to make this probability high for real text and low for nonsense. With enough parameters and data, patterns at many levels — grammar, facts, logic — get encoded into the same set of weights.

The key pattern. More capacity (parameters) + more diverse data + longer training = broader generalization. But raw size isn't magic; the training objective still only predicts the next token. Every capability you observe — answering questions, solving math — emerges from doing that one thing extremely well across an enormous range of examples.
