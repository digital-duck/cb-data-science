Activation Function

You already have the intuition: a neuron in a neural network receives signals, adds them up, and then decides whether to "fire." The activation function is the mechanism behind that decision — it takes the weighted sum arriving at a neuron and transforms it into an output that gets passed forward.

Without an activation function, stacking layers of a neural network would be pointless. Each layer would just compute a linear combination of its inputs, and no matter how many layers you add, the whole network collapses into a single linear map. Activation functions introduce nonlinearity, which is what lets deep networks learn curves, boundaries, and complex patterns.

One of the most common modern choices is the ReLU (Rectified Linear Unit):

$$f(x) = \max(0,\, x)$$

It is beautifully simple: negative inputs become zero, positive inputs pass through unchanged. Another classic is the sigmoid, which squashes any real number into the range $(0, 1)$:

$$\sigma(x) = \frac{1}{1 + e^{-x}}$$

Sigmoid is useful when you need to interpret an output as a probability. Both functions share a key property: they are nonlinear, so composing many of them across layers creates expressive, flexible models.

A useful mental rule: ReLU is the default workhorse for hidden layers; sigmoid (or its cousin softmax) belongs at the output when you need probabilities.
