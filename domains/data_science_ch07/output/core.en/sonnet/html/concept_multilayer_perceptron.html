Multilayer Perceptron

Recap: You already know that a single neuron takes a weighted sum of its inputs, adds a bias, and passes the result through an activation function. That one neuron is a capable building block — but most real problems are far too tangled for it to handle alone.

Explore the structure: The fix is to stack neurons into layers. A multilayer perceptron (MLP) organizes neurons into three roles:

  • Input layer — receives raw data (pixel values, sensor readings)
  • Hidden layers — transform the data step by step into more useful patterns
  • Output layer — delivers the final answer or prediction

    • Each neuron in a hidden layer looks at every output from the layer before it and computes a weighted sum plus a bias — exactly like the single neuron you already know, just wired to a whole layer instead of one input. If neuron $j$ in layer $\ell$ receives activations $a_i^{(\ell-1)}$ from the previous layer, its pre-activation is:

    $$z_j^{(\ell)} = \sum_i w_{ji}^{(\ell)}\, a_i^{(\ell-1)} + b_j^{(\ell)}$$

    Then the neuron applies its activation function and sends the result to the next layer. Data flows forward through every layer until it reaches the output.

    One critical point: nonlinear activations are what make stacking layers worthwhile. Without them, any stack of layers — no matter how deep — collapses into a single linear rule, gaining nothing from the depth.

    The pattern: Each layer takes a step further from raw data toward meaning. Early layers detect low-level details; later layers combine those into higher-level ideas. More layers → richer representations.

    Practice problem: A hidden neuron receives inputs $a_1 = 2$ and $a_2 = -1$ with weights $w_1 = 0.5$, $w_2 = 1.0$, and bias $b = 0.3$. Compute $z$. If the network uses ReLU, what is the neuron's output?
