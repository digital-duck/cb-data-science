Perceptron

You have probably heard that a neuron "fires" when it gets enough input. A perceptron captures that idea in math: it adds up weighted signals and decides yes or no based on the total.

Formally, suppose you have inputs $x_1, x_2, \ldots, x_n$ and matching weights $w_1, w_2, \ldots, w_n$. The perceptron computes a weighted sum:

$$z = w_1 x_1 + w_2 x_2 + \cdots + w_n x_n + b$$

where $b$ is a bias — a constant that shifts the threshold, so the decision boundary does not have to pass through the origin. Think of $z$ as a total score. The perceptron then applies one simple rule:

$$\hat{y} = \begin{cases} 1 & \text{if } z \geq 0 \\ 0 & \text{if } z < 0 \end{cases}$$

Score above zero → output 1 ("yes"). Score below zero → output 0 ("no").

The weights are the key: each $w_i$ controls how much input $x_i$ matters. A large positive weight means "this input pushes strongly toward yes." A negative weight means "this input pushes toward no." The bias lets you fine-tune the tipping point independently of the inputs themselves.

A single perceptron draws one straight boundary between two classes — it can separate "yes" examples from "no" examples only when that boundary is a line (or a flat plane in higher dimensions).

Practice problem: A perceptron has weights $w_1 = 0.5$, $w_2 = -1.0$, and bias $b = 0.2$. Given inputs $x_1 = 3$ and $x_2 = 1$, compute $z$ and state the perceptron's output $\hat{y}$.
