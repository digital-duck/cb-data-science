Concept Book: Predictive Analytics

Data Science Ch01 · Generated by SPL

Payoff

You have spent time learning how to find patterns in data — fitting lines, spotting trends, measuring how two things move together. Predictive analytics is what happens when those skills grow up and start doing real work: instead of just describing the past, you use what you learned to make a confident, quantified guess about something you have not seen yet.

The core idea is a function that maps known inputs to an unknown output. Written simply, you are looking for $\hat{y} = f(x_1, x_2, \ldots, x_n)$, where the hat on $\hat{y}$ signals that this is a prediction, not a certain fact. The inputs might be a person's age, location, and browsing history; the output might be a number representing how likely they are to enjoy a particular movie. Every technique you have studied — averages, correlations, linear models — feeds directly into building and testing that function $f$.

This is exactly how a recommendation system works. A streaming service does not guess randomly when it suggests a show. It builds a predictive model trained on millions of viewing records, finds patterns in what similar users watched next, and outputs a ranked list: $\hat{y}_1 > \hat{y}_2 > \hat{y}_3 > \cdots$. The system is a predictive analytics engine running quietly in the background every time you open the app.

The invitation now is to go deeper into one of those engines. Recommendation systems are a fascinating place to start — they blend linear algebra, probability, and real human behavior into something you interact with every day.

Practice problem: A model predicts you will rate Movie A at $\hat{y} = 4.2$ stars and Movie B at $\hat{y} = 3.7$ stars. If your actual ratings turn out to be $4.0$ and $4.5$, compute the prediction error for each movie. Which prediction was more accurate, and by how much?
