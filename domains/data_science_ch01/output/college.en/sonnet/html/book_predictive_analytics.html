Concept Book: Predictive Analytics

Data Science Ch01 · Generated by SPL

Payoff

Predictive analytics is the discipline of constructing a mapping $\hat{f}: \mathcal{X} \to \mathcal{Y}$ from observable features $\mathbf{x} \in \mathcal{X}$ to an outcome $y \in \mathcal{Y}$ that has not yet been measured, using patterns extracted from historical data $\mathcal{D} = \{(\mathbf{x}_i, y_i)\}_{i=1}^n$. Every concept developed in the preceding chapters — limits, derivatives, linear algebra, probability, and optimization — converges here. The derivative tells us how a loss surface slopes; linear algebra gives us the matrix operations that transform high-dimensional feature spaces; probability supplies the likelihood framework that quantifies uncertainty in our estimates. Predictive analytics is not merely an application of these ideas; it is the lens that reveals why each idea was worth developing.

Worked example. Suppose a streaming platform records whether user $u$ watched film $f$: let $r_{u,f} \in \{0,1\}$. We embed every user and film into $\mathbb{R}^k$ via latent vectors $\mathbf{p}_u, \mathbf{q}_f$ and predict

$$\hat{r}_{u,f} = \sigma\!\left(\mathbf{p}_u^{\top}\mathbf{q}_f + b_u + b_f\right), \qquad \sigma(z) = \frac{1}{1+e^{-z}}.$$

We minimize the binary cross-entropy

$$\mathcal{L} = -\frac{1}{|\mathcal{D}|}\sum_{(u,f)\in\mathcal{D}}\bigl[r_{u,f}\ln\hat{r}_{u,f} + (1-r_{u,f})\ln(1-\hat{r}_{u,f})\bigr]$$

via stochastic gradient descent: $\mathbf{p}_u \leftarrow \mathbf{p}_u - \eta\,\partial\mathcal{L}/\partial\mathbf{p}_u$. After convergence, $\hat{r}_{u,f}$ ranks unseen films for each user — a fully operational recommendation system.

Theorem (Universal Approximation, informal). For any continuous target function $g: [0,1]^d \to \mathbb{R}$ and tolerance $\varepsilon > 0$, there exists a one-hidden-layer neural network $\hat{f}$ such that $\sup_{\mathbf{x}}|g(\mathbf{x}) - \hat{f}(\mathbf{x})| < \varepsilon$. This guarantees that, given sufficient data and capacity, predictive models can represent arbitrarily complex decision boundaries — underpinning the recommendation engine's ability to capture subtle user taste.

Connection to recommendation systems. A recommendation system operationalizes predictive analytics at scale: it predicts the relevance score $\hat{r}_{u,f}$ for every unobserved (user, item) pair and surfaces the top-$K$ items by ranked score. The statistical machinery — matrix factorization, gradient descent, regularization to prevent overfitting — is identical to the general predictive framework; only the semantics of $\mathcal{Y}$ (relevance rather than, say, credit risk) changes.

from sympy import symbols, exp, log, diff, simplify

z = symbols('z', real=True)
sigma = 1 / (1 + exp(-z))
loss = -log(sigma)          # cross-entropy for a positive label
grad = diff(loss, z)
print("d(loss)/dz =", simplify(grad))   # expects sigma - 1

The gradient computed above — $\sigma(z) - 1$ — is precisely the update signal that drives embedding vectors toward agreement with observed interactions. With this derivation in hand, you are equipped to step inside a production recommendation engine and understand every moving part. The next chapter invites you to do exactly that.
