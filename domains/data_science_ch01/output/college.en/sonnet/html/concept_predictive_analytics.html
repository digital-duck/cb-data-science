Predictive Analytics

Definition. Predictive analytics is the branch of data science concerned with constructing mathematical models that, given a set of observed input variables $\mathbf{x} = (x_1, x_2, \ldots, x_p)^{\top}$, produce an estimate $\hat{y}$ of an unobserved target variable $y$. Formally, we seek a function $f : \mathbb{R}^p \to \mathbb{R}$ such that the expected prediction error

$$\mathcal{L}(f) = \mathbb{E}\!\left[(y - f(\mathbf{x}))^2\right]$$

is minimised over the joint distribution of $(\mathbf{x}, y)$. The minimiser of this squared-error loss is the conditional expectation $f^*(\mathbf{x}) = \mathbb{E}[y \mid \mathbf{x}]$, which serves as the theoretical gold standard against which practical models are evaluated.

Worked Example. Suppose a university wishes to predict a student's final examination score $y$ from two features: hours studied per week $x_1$ and prior GPA $x_2$. After collecting $n = 200$ observations, an analyst fits the ordinary least-squares (OLS) model

$$\hat{y} = \hat{\beta}_0 + \hat{\beta}_1 x_1 + \hat{\beta}_2 x_2,$$

where the coefficient vector $\hat{\boldsymbol{\beta}} = (X^{\top}X)^{-1}X^{\top}\mathbf{y}$ is obtained by solving the normal equations, $X$ being the $200 \times 3$ design matrix with a leading column of ones. If the fitted coefficients are $\hat{\beta}_0 = 42.1$, $\hat{\beta}_1 = 1.8$, and $\hat{\beta}_2 = 6.3$, then a student who studies $10$ hours per week and holds a prior GPA of $3.5$ receives the prediction $\hat{y} = 42.1 + 1.8(10) + 6.3(3.5) = 82.15$ points.

Key Theorem (Bias–Variance Decomposition). For any estimator $\hat{f}$ and a fixed point $\mathbf{x}_0$, the expected squared prediction error decomposes as

$$\mathbb{E}\!\left[(y - \hat{f}(\mathbf{x}_0))^2\right] = \underbrace{\left(\mathbb{E}[\hat{f}(\mathbf{x}_0)] - f^*(\mathbf{x}_0)\right)^2}_{\text{Bias}^2} + \underbrace{\mathrm{Var}(\hat{f}(\mathbf{x}_0))}_{\text{Variance}} + \underbrace{\sigma^2}_{\text{Irreducible noise}}.$$

This result, proved by expanding the square and applying linearity of expectation, reveals the fundamental trade-off in model selection: reducing model complexity lowers variance but inflates bias, while increasing complexity has the opposite effect.

from sympy import symbols, Matrix

b0, b1, b2 = 42.1, 1.8, 6.3
x1_val, x2_val = 10, 3.5
y_hat = b0 + b1 * x1_val + b2 * x2_val
print(f"Predicted score: {y_hat}")   # 82.15
