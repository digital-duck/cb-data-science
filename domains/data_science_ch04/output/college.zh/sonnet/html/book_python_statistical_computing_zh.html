Python 统计计算的达成

回顾全书,我们从概率分布、抽样与估计出发,一路走到假设检验与回归。这些概念在纸面上各自成立,但真实数据往往有上百万行,手算既不可能也不可靠。Python 统计计算把这条链路变成可执行、可复现的流程:用 NumPy 做向量化数值运算,用 pandas 整理数据,用 SciPy/statsmodels 做推断,用 matplotlib 做可视化。

它之所以是自然的终点,是因为它把理论与实践合二为一。例如,大数定律告诉我们样本均值收敛于期望:

$$\bar{X}_n=\frac1n\sum_{i=1}^n X_i \xrightarrow{\;P\;} \mu .$$

借助模拟,我们可以直接"看见"这个结论:

import numpy as np
rng = np.random.default_rng(0)
for n in (10, 1_000, 100_000):
    x = rng.exponential(scale=2.0, size=n)   # 真实均值 μ = 2
    print(n, x.mean())

随着 $n$ 增大,输出越来越接近 $2$。同样,自助法(bootstrap)用重复重采样估计标准误:

data = rng.normal(5, 2, 200)
boots = [rng.choice(data, data.size).mean() for _ in range(5000)]
print(np.std(boots))   # 约等于 2/√200 ≈ 0.141

这里公式 $\mathrm{SE}=\sigma/\sqrt{n}$ 与代码结果相互印证——理论预测可以被计算验证,计算结果又能被理论解释。

与各应用领域的联系

本节未列出具体的应用领域,但统计计算的通用能力可以延伸到以下几类典型方向(请根据你的课程选择):

  • 数据科学与机器学习:线性回归 $\hat\beta=(X^\top X)^{-1}X^\top y$ 在 statsmodels 中一行即可拟合;交叉验证则是对泛化误差的重采样估计。
  • 自然科学实验分析:误差传播、曲线拟合与置信区间,可用 scipy.optimize.curve_fit 与自助法完成。
  • 金融与风险管理:蒙特卡洛模拟估计在险价值(VaR),本质上是对分布分位数的估计。
  • 医学与社会科学:A/B 测试、生存分析与因果推断,依赖假设检验与功效分析的计算实现。

    • 它们的共同模式是:建立模型 → 用代码估计 → 用不确定性量化检验结论。
